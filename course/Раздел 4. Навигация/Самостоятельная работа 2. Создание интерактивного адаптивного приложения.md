# Самостоятельная работа 2. Создание спортивного приложения

В этой работе вы закрепите тему адаптивных макетов, создав приложение **Sports**. Стартовое приложение полностью работает на телефоне. Ваша задача — адаптировать его для больших экранов.

### Пререквизиты

- Самостоятельная работа 1 «Адаптивный макет».
- Умение пользоваться `useWindowDimensions`.
- Знание навигации.

### Что вы узнаете

- Как определить подходящий макет для большого экрана.
- Как показать список и подробности рядом.
- Как управлять поведением кнопки «Назад» на разных макетах.

### Что вы создадите

Спортивное приложение, адаптирующееся к большому экрану.

## Экран списка и экран деталей

В мобильной версии есть два экрана:

- **`SportsList`** — список видов спорта.
- **`SportsDetail`** — подробности выбранного вида спорта.

На большом экране эти два экрана объединяются в один: слева список, справа подробности.

## Шаг 1. Определите макет

Нарисуйте эскиз расширенного макета: список слева, детали справа. Такой макет называют **list-and-detail**.

## Шаг 2. Компонент SportsListAndDetails

Создайте компонент, который показывает и список, и подробности одновременно:

```tsx
type Sport = { id: string; name: string; description: string }

function SportsListAndDetails({ sports }: { sports: Sport[] }) {
  const [selected, setSelected] = useState<Sport | null>(null)

  return (
    <View style={styles.row}>
      <View style={styles.listPane}>
        <FlatList
          data={sports}
          keyExtractor={(item) => item.id}
          renderItem={({ item }) => (
            <Pressable
              style={[styles.item, selected?.id === item.id && styles.itemSelected]}
              onPress={() => setSelected(item)}
            >
              <Text style={styles.itemText}>{item.name}</Text>
            </Pressable>
          )}
        />
      </View>
      <View style={styles.detailPane}>
        <SportsDetail sport={selected} />
      </View>
    </View>
  )
}
```

## Шаг 3. Компонент деталей

`SportsDetail` показывает подробности или подсказку, если ничего не выбрано:

```tsx
function SportsDetail({ sport }: { sport: Sport | null }) {
  if (!sport) {
    return <Text style={styles.hint}>Выберите вид спорта</Text>
  }
  return (
    <>
      <Text style={styles.title}>{sport.name}</Text>
      <Text style={styles.body}>{sport.description}</Text>
    </>
  )
}
```

## Шаг 4. Переключение по размеру окна

```tsx
type ContentType = 'ListOnly' | 'ListAndDetail'

function useContentType(): ContentType {
  const { width } = useWindowDimensions()
  return width < 600 ? 'ListOnly' : 'ListAndDetail'
}
```

В главном компоненте выбираем макет:

```tsx
function SportsApp({ onOpenList }: { onOpenList: () => void }) {
  const contentType = useContentType()
  const [sports] = useState<Sport[]>([
    { id: '1', name: 'Футбол', description: 'Командная игра с мячом.' },
    { id: '2', name: 'Теннис', description: 'Игра с ракеткой и мячом.' },
    { id: '3', name: 'Плавание', description: 'Водный вид спорта.' },
  ])

  if (contentType === 'ListAndDetail') {
    return <SportsListAndDetails sports={sports} />
  }
  return <SportsList sports={sports} onSportPressed={onOpenList} />
}
```

## Шаг 5. Панель приложения и кнопка «Назад»

На компактном экране на экране деталей показывается кнопка «Назад». На большом экране кнопка не нужна: пользователь остаётся на главном экране, а выход из приложения выполняет системная кнопка «Назад».

```tsx
function SportsAppBar({ isDetail, onBack }: { isDetail: boolean; onBack: () => void }) {
  return (
    <View style={styles.appBar}>
      {isDetail && (
        <Pressable onPress={onBack}>
          <Text style={styles.back}>← Назад</Text>
        </Pressable>
      )}
      <Text style={styles.appBarTitle}>Sports</Text>
    </View>
  )
}
```

Передавайте `isDetail = contentType === 'ListOnly' && открыт детальный экран`. На расширенном макете `isDetail` всегда `false`.

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import {
  FlatList,
  Pressable,
  StyleSheet,
  Text,
  useWindowDimensions,
  View,
} from 'react-native';

type Sport = { id: string; name: string; description: string }
type ContentType = 'ListOnly' | 'ListAndDetail'

function useContentType(): ContentType {
  const { width } = useWindowDimensions()
  return width < 600 ? 'ListOnly' : 'ListAndDetail'
}

function SportsDetail({ sport }: { sport: Sport | null }) {
  if (!sport) return <Text style={styles.hint}>Выберите вид спорта</Text>
  return (
    <>
      <Text style={styles.title}>{sport.name}</Text>
      <Text style={styles.body}>{sport.description}</Text>
    </>
  )
}

function SportsList({
  sports,
  onSportPressed,
}: {
  sports: Sport[]
  onSportPressed: (sport: Sport) => void
}) {
  return (
    <FlatList
      data={sports}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <Pressable style={styles.item} onPress={() => onSportPressed(item)}>
          <Text style={styles.itemText}>{item.name}</Text>
        </Pressable>
      )}
    />
  )
}

function SportsListAndDetails({ sports }: { sports: Sport[] }) {
  const [selected, setSelected] = useState<Sport | null>(null)
  return (
    <View style={styles.row}>
      <View style={styles.listPane}>
        <FlatList
          data={sports}
          keyExtractor={(item) => item.id}
          renderItem={({ item }) => (
            <Pressable
              style={[styles.item, selected?.id === item.id && styles.itemSelected]}
              onPress={() => setSelected(item)}
            >
              <Text style={styles.itemText}>{item.name}</Text>
            </Pressable>
          )}
        />
      </View>
      <View style={styles.detailPane}>
        <SportsDetail sport={selected} />
      </View>
    </View>
  )
}

export default function App() {
  const contentType = useContentType()
  const [sports] = useState<Sport[]>([
    { id: '1', name: 'Футбол', description: 'Командная игра с мячом.' },
    { id: '2', name: 'Теннис', description: 'Игра с ракеткой и мячом.' },
    { id: '3', name: 'Плавание', description: 'Водный вид спорта.' },
  ])
  const [selected, setSelected] = useState<Sport | null>(null)

  const isDetail = contentType === 'ListOnly' && selected != null

  return (
    <View style={styles.container}>
      <View style={styles.appBar}>
        {isDetail && (
          <Pressable onPress={() => setSelected(null)}>
            <Text style={styles.back}>← Назад</Text>
          </Pressable>
        )}
        <Text style={styles.appBarTitle}>Sports</Text>
      </View>

      {contentType === 'ListAndDetail' ? (
        <SportsListAndDetails sports={sports} />
      ) : isDetail ? (
        <View style={styles.detailPane}>
          <SportsDetail sport={selected} />
        </View>
      ) : (
        <SportsList sports={sports} onSportPressed={setSelected} />
      )}
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#F5F5F5' },
  appBar: {
    flexDirection: 'row',
    alignItems: 'center',
    padding: 16,
    backgroundColor: '#3F51B5',
    gap: 16,
  },
  appBarTitle: { color: '#FFF', fontSize: 20, fontWeight: 'bold' },
  back: { color: '#FFF', fontSize: 16 },
  row: { flex: 1, flexDirection: 'row' },
  listPane: { width: 320, borderRightWidth: 1, borderRightColor: '#DDD' },
  detailPane: { flex: 1, padding: 24 },
  item: {
    padding: 16,
    borderBottomWidth: 1,
    borderBottomColor: '#EEE',
    backgroundColor: '#FFF',
  },
  itemSelected: { backgroundColor: '#E8EAF6' },
  itemText: { fontSize: 16 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 16 },
  body: { fontSize: 16 },
  hint: { fontSize: 16, color: '#888' },
})
```

## Проверка адаптивности

- На телефоне: список → нажатие → детали с кнопкой «Назад».
- На планшете: список и детали рядом, кнопки «Назад» нет.
- Поворачивайте устройство и меняйте размер окна в веб-версии Expo, чтобы убедиться в перестройке макета.

## Итог

- Канонический макет **list-and-detail** подходит для больших экранов.
- `useWindowDimensions` определяет тип содержимого.
- Поведение кнопки «Назад» зависит от текущего макета.
