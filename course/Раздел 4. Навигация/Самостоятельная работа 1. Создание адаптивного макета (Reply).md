# Самостоятельная работа 1. Создание приложения с адаптивным макетом

В предыдущей работе вы познакомились с навигацией между экранами. Теперь научимся строить **адаптивный макет**, который подстраивается под размер экрана: на телефоне — только список, на планшете — список и подробности рядом.

### Пререквизиты

- Умение создавать состояние и компоненты.
- Знание навигации (лекция 9).

### Что вы узнаете

- Как получить размеры экрана через `useWindowDimensions`.
- Как выбрать макет в зависимости от ширины (`LIST_ONLY` / `LIST_AND_DETAIL`).
- Как протестировать разные размеры экрана.

### Что вы создадите

Вы продолжите приложение **Reply** (почтовый клиент) и сделаете его адаптивным для всех размеров экрана.

## Классы размеров окна

Ширину окна получают хуком **`useWindowDimensions`**, который автоматически обновляется при повороте устройства и изменении размера окна:

```tsx
import { useWindowDimensions } from 'react-native'

const { width, height } = useWindowDimensions()
```

Определим классы ширины окна:

- **Compact** — меньше 600 dp.
- **Medium** — от 600 до 840 dp.
- **Expanded** — больше 840 dp.

```tsx
type SizeClass = 'compact' | 'medium' | 'expanded'

function useSizeClass(): SizeClass {
  const { width } = useWindowDimensions()
  if (width < 600) return 'compact'
  if (width < 840) return 'medium'
  return 'expanded'
}
```

## Типы макета и навигации

Введём два перечисления:

```tsx
type ContentType = 'LIST_ONLY' | 'LIST_AND_DETAIL'
type NavigationType = 'BOTTOM_NAVIGATION' | 'PERMANENT_NAVIGATION_DRAWER'
```

- `LIST_ONLY` — показывается только список писем (телефон).
- `LIST_AND_DETAIL` — список слева и подробности справа (планшет).

## Компонент списка и подробностей

```tsx
function ReplyListOnlyContent({ emails, onEmailCardPressed }: {
  emails: Email[]
  onEmailCardPressed: (email: Email) => void
}) {
  return (
    <FlatList
      data={emails}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <Pressable style={styles.card} onPress={() => onEmailCardPressed(item)}>
          <Text style={styles.cardTitle}>{item.subject}</Text>
          <Text>{item.sender}</Text>
        </Pressable>
      )}
    />
  )
}

function ReplyListAndDetailContent({ emails, onEmailCardPressed }: {
  emails: Email[]
  onEmailCardPressed: (email: Email) => void
}) {
  const [selected, setSelected] = useState<Email | null>(null)

  return (
    <View style={styles.row}>
      <View style={styles.listPane}>
        <ReplyListOnlyContent
          emails={emails}
          onEmailCardPressed={(email) => setSelected(email)}
        />
      </View>
      <View style={styles.detailPane}>
        {selected ? (
          <>
            <Text style={styles.cardTitle}>{selected.subject}</Text>
            <Text>{selected.sender}</Text>
            <Text style={styles.body}>{selected.body}</Text>
          </>
        ) : (
          <Text>Выберите письмо</Text>
        )}
      </View>
    </View>
  )
}
```

## Главный компонент с выбором макета

```tsx
function ReplyApp() {
  const sizeClass = useSizeClass()
  const contentType: ContentType =
    sizeClass === 'compact' ? 'LIST_ONLY' : 'LIST_AND_DETAIL'

  const [emails] = useState<Email[]>([
    { id: '1', subject: 'Привет', sender: 'Анна', body: 'Текст письма 1' },
    { id: '2', subject: 'Отчёт', sender: 'Иван', body: 'Текст письма 2' },
  ])

  return (
    <View style={styles.container}>
      {contentType === 'LIST_AND_DETAIL' ? (
        <ReplyListAndDetailContent emails={emails} onEmailCardPressed={() => {}} />
      ) : (
        <ReplyListOnlyContent emails={emails} onEmailCardPressed={() => {}} />
      )}
    </View>
  )
}
```

Так на узком экране показывается только список, а на широком — список и подробности одновременно.

## Тестирование на разных размерах

Чтобы проверить адаптивность:

1. Запустите приложение на эмуляторе телефона и планшета.
2. Поверните устройство — `useWindowDimensions` вернёт новую ширину, и макет перестроится.
3. В веб-версии Expo (`npx expo start --web`) просто изменяйте ширину окна браузера.

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import {
  FlatList,
  Pressable,
  StyleSheet,
  Text,
  useWindowDimensions,
  View,
} from 'react-native';

type Email = { id: string; subject: string; sender: string; body: string }

type SizeClass = 'compact' | 'medium' | 'expanded'
type ContentType = 'LIST_ONLY' | 'LIST_AND_DETAIL'

function useSizeClass(): SizeClass {
  const { width } = useWindowDimensions()
  if (width < 600) return 'compact'
  if (width < 840) return 'medium'
  return 'expanded'
}

function ReplyListOnlyContent({
  emails,
  onEmailCardPressed,
}: {
  emails: Email[]
  onEmailCardPressed: (email: Email) => void
}) {
  return (
    <FlatList
      data={emails}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <Pressable style={styles.card} onPress={() => onEmailCardPressed(item)}>
          <Text style={styles.cardTitle}>{item.subject}</Text>
          <Text>{item.sender}</Text>
        </Pressable>
      )}
    />
  )
}

function ReplyListAndDetailContent({
  emails,
  onEmailCardPressed,
}: {
  emails: Email[]
  onEmailCardPressed: (email: Email) => void
}) {
  const [selected, setSelected] = useState<Email | null>(null)
  return (
    <View style={styles.row}>
      <View style={styles.listPane}>
        <ReplyListOnlyContent emails={emails} onEmailCardPressed={setSelected} />
      </View>
      <View style={styles.detailPane}>
        {selected ? (
          <>
            <Text style={styles.cardTitle}>{selected.subject}</Text>
            <Text>{selected.sender}</Text>
            <Text style={styles.body}>{selected.body}</Text>
          </>
        ) : (
          <Text>Выберите письмо</Text>
        )}
      </View>
    </View>
  )
}

function ReplyApp() {
  const sizeClass = useSizeClass()
  const contentType: ContentType =
    sizeClass === 'compact' ? 'LIST_ONLY' : 'LIST_AND_DETAIL'

  const [emails] = useState<Email[]>([
    { id: '1', subject: 'Привет', sender: 'Анна', body: 'Текст письма 1' },
    { id: '2', subject: 'Отчёт', sender: 'Иван', body: 'Текст письма 2' },
  ])

  return (
    <View style={styles.container}>
      {contentType === 'LIST_AND_DETAIL' ? (
        <ReplyListAndDetailContent emails={emails} onEmailCardPressed={() => {}} />
      ) : (
        <ReplyListOnlyContent emails={emails} onEmailCardPressed={() => {}} />
      )}
    </View>
  )
}

export default function App() {
  return (
    <>
      <ReplyApp />
      <StatusBar style="auto" />
    </>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#F5F5F5' },
  row: { flex: 1, flexDirection: 'row' },
  listPane: { width: 320, borderRightWidth: 1, borderRightColor: '#DDD' },
  detailPane: { flex: 1, padding: 24 },
  card: {
    padding: 16,
    borderBottomWidth: 1,
    borderBottomColor: '#EEE',
    backgroundColor: '#FFF',
  },
  cardTitle: { fontSize: 16, fontWeight: 'bold', marginBottom: 4 },
  body: { marginTop: 16 },
})
```

## Итог

- `useWindowDimensions` даёт ширину и высоту экрана и обновляется при изменениях.
- Класс размера окна определяет, какой макет показывать.
- `LIST_ONLY` — для телефона, `LIST_AND_DETAIL` — для планшета.
- Адаптивность проверяют на разных устройствах и в веб-версии.
