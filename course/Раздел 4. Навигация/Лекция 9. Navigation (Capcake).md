# Лекция 9. Навигация в React Native

В этом уроке вы научитесь перемещаться между экранами приложения. Вы создадите приложение **Cupcake** — заказ кексов, состоящий из нескольких экранов.

### Пререквизиты

- Умение создавать состояние (`useState`) и управляемые поля.
- Базовое представление о компонентах и свойствах.

### Что вы узнаете

- Как установить и настроить библиотеку **React Navigation**.
- Как создать стек экранов (`Stack Navigator`).
- Как переходить между экранами и возвращаться назад.
- Как передавать данные между экранами через параметры.

### Что вы создадите

Приложение **Cupcake** с экранами: выбор вкуса → выбор даты → итоговый экран с отправкой заказа.

## Установка React Navigation

В проекте Expo установите библиотеки навигации:

```
npx expo install @react-navigation/native @react-navigation/native-stack
npx expo install react-native-screens react-native-safe-area-context
```

- `@react-navigation/native` — ядро навигации.
- `@react-navigation/native-stack` — навигатор стека (экраны кладутся друг на друга, как карточки).

## Основы: навигатор стека

Навигатор стека хранит историю экранов. Каждый новый экран кладётся сверху, а кнопка «Назад» возвращает к предыдущему.

Создают навигатор так:

```tsx
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';

const Stack = createNativeStackNavigator();

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="Start" component={StartScreen} />
        <Stack.Screen name="Flavor" component={FlavorScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}
```

- `NavigationContainer` — корневой контейнер, управляет всем деревом навигации.
- `Stack.Screen` — один экран; свойство `name` — его имя (используется при переходах).

## Экраны приложения Cupcake

Создадим четыре экрана:

1. **Start** — стартовый экран с кнопкой «Заказать».
2. **Flavor** — выбор вкуса кекса.
3. **Pickup** — выбор даты получения.
4. **Summary** — итог заказа и отправка.

## Экран Start

```tsx
function StartScreen({ navigation }: { navigation: any }) {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Заказать кекс</Text>
      <Button title="Начать" onPress={() => navigation.navigate('Flavor')} />
    </View>
  )
}
```

`navigation.navigate('Flavor')` открывает экран с именем `Flavor`.

> Все экраны получают объект `navigation` через свойства. Для строгой типизации в React Native используют `NativeStackScreenProps`, но здесь, для простоты, тип `any`.

## Экран Flavor

```tsx
function FlavorScreen({ navigation }: { navigation: any }) {
  const [flavor, setFlavor] = useState<string | null>(null)

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Выберите вкус</Text>
      {['Ваниль', 'Шоколад', 'Клубника'].map((name) => (
        <View key={name} style={styles.row}>
          <Text>{name}</Text>
          <RadioButton
            selected={flavor === name}
            onPress={() => setFlavor(name)}
          />
        </View>
      ))}
      <Button
        title="Далее"
        disabled={flavor === null}
        onPress={() => navigation.navigate('Pickup', { flavor })}
      />
    </View>
  )
}
```

## Передача данных между экранами

Второй аргумент `navigate` — объект параметров. Получить их на другом экране можно через `route.params`:

```tsx
function PickupScreen({ navigation, route }: { navigation: any; route: any }) {
  const { flavor } = route.params
  const [date, setDate] = useState<Date | null>(null)

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Вкус: {flavor}</Text>
      <Text style={styles.title}>Выберите дату получения</Text>
      <Button
        title="Далее"
        disabled={date === null}
        onPress={() => navigation.navigate('Summary', { flavor, date })}
      />
    </View>
  )
}
```

## Итоговый экран и отправка

На экране Summary покажем выбранные параметры и кнопку отправки заказа через системный диалог `Share`:

```tsx
import { Share } from 'react-native'

function SummaryScreen({ route }: { route: any }) {
  const { flavor, date } = route.params

  const shareOrder = async () => {
    await Share.share({
      message: `Заказ: кекс ${flavor}, дата: ${date}`,
    })
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Ваш заказ</Text>
      <Text>Вкус: {flavor}</Text>
      <Text>Дата: {date}</Text>
      <Button title="Отправить заказ" onPress={shareOrder} />
    </View>
  )
}
```

## Возврат назад

- Кнопка «Назад» в заголовке появляется автоматически на вложенных экранах.
- Программно вернуться можно так: `navigation.goBack()`.
- Вернуться к первому экрану стека: `navigation.popToTop()`.

## Полный код App.tsx

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import { Button, StyleSheet, Text, View } from 'react-native';
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';

const Stack = createNativeStackNavigator();

function StartScreen({ navigation }: { navigation: any }) {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Заказать кекс</Text>
      <Button title="Начать" onPress={() => navigation.navigate('Flavor')} />
    </View>
  )
}

function FlavorScreen({ navigation }: { navigation: any }) {
  const [flavor, setFlavor] = useState<string | null>(null)
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Выберите вкус</Text>
      {['Ваниль', 'Шоколад', 'Клубника'].map((name) => (
        <Button
          key={name}
          title={flavor === name ? `✓ ${name}` : name}
          onPress={() => setFlavor(name)}
        />
      ))}
      <Button
        title="Далее"
        disabled={flavor === null}
        onPress={() => navigation.navigate('Pickup', { flavor })}
      />
    </View>
  )
}

function PickupScreen({ navigation, route }: { navigation: any; route: any }) {
  const { flavor } = route.params
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Вкус: {flavor}</Text>
      <Button
        title="Далее"
        onPress={() => navigation.navigate('Summary', { flavor, date: '2026-01-01' })}
      />
    </View>
  )
}

function SummaryScreen({ route }: { route: any }) {
  const { flavor, date } = route.params
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Ваш заказ</Text>
      <Text>Вкус: {flavor}</Text>
      <Text>Дата: {date}</Text>
    </View>
  )
}

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Start">
        <Stack.Screen name="Start" component={StartScreen} options={{ title: 'Cupcake' }} />
        <Stack.Screen name="Flavor" component={FlavorScreen} options={{ title: 'Вкус' }} />
        <Stack.Screen name="Pickup" component={PickupScreen} options={{ title: 'Дата' }} />
        <Stack.Screen name="Summary" component={SummaryScreen} options={{ title: 'Итог' }} />
      </Stack.Navigator>
      <StatusBar style="auto" />
    </NavigationContainer>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
    padding: 40,
  },
  title: { fontSize: 20, marginBottom: 16 },
})
```

## Резюме

- `NavigationContainer` — корень навигации.
- `Stack.Navigator` / `Stack.Screen` описывают экраны.
- `navigation.navigate('Имя')` открывает экран, `goBack()` возвращает назад.
- Данные передаются через параметры: `navigate('Имя', { ... })` и `route.params`.
