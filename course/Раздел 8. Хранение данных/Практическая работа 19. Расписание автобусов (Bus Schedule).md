### Пререквизиты

### Что вы узнаете

- Как загружать данные из JSON-файла в SQLite при первом запуске.
- Как построить многоэкранное приложение с использованием SQLite.
- Как динамически обновлять данные в списке.

### Что вы создадите

Приложение **Bus Schedule** со списком остановок и расписанием отправлений.

## Структура данных

Допустим, стартовый JSON содержит расписание:

```json
[
  { "id": 1, "stop": "Улица Ленина", "time": "08:00" },
  { "id": 2, "stop": "Центральная площадь", "time": "08:15" },
  { "id": 3, "stop": "Парк Победы", "time": "08:30" },

```

## Создание базы и таблицы

```tsx
import * as SQLite from 'expo-sqlite'
import scheduleData from './assets/schedule.json'

type ScheduleEntry = { id: number; stop: string; time: string }

export async function initDatabase(): Promise<SQLite.SQLiteDatabase> {
  const db = await SQLite.openDatabaseAsync('bus-schedule.db')

  await db.execAsync(`
    CREATE TABLE IF NOT EXISTS schedule (
      id INTEGER PRIMARY KEY,
      stop TEXT NOT NULL,
      time TEXT NOT NULL
    )
  `)

  const count = await db.getFirstAsync<{ count: number }>(
    'SELECT COUNT(*) as count FROM schedule'
  )

  if (count && count.count === 0) {
    for (const entry of scheduleData) {
      await db.runAsync(
        'INSERT INTO schedule (id, stop, time) VALUES (?, ?, ?)',
        entry.id, entry.stop, entry.time
      )
    }
  }

  return db
}
```

Загрузка данных из JSON происходит только при первом запуске (проверка по `COUNT`).

## Получение списка остановок

```tsx
export async function getStops(
  db: SQLite.SQLiteDatabase
): Promise<string[]> {
  const rows = await db.getAllAsync<{ stop: string }>(
    'SELECT DISTINCT stop FROM schedule ORDER BY stop'
  )
  return rows.map((r) => r.stop)
}
```

## Получение расписания для остановки

```tsx
export async function getSchedule(
  db: SQLite.SQLiteDatabase,
  stop: string
): Promise<ScheduleEntry[]> {
  return await db.getAllAsync<ScheduleEntry>(
    'SELECT * FROM schedule WHERE stop = ? ORDER BY time',
    stop
  )
}
```

## Экран списка остановок

```tsx
function StopsList({ db, onStopSelected }: {
  db: SQLite.SQLiteDatabase
  onStopSelected: (stop: string) => void
}) {
  const [stops, setStops] = useState<string[]>([])

  useEffect(() => {
    getStops(db).then(setStops)
  }, [])

  return (
    <FlatList
      data={stops}
      keyExtractor={(item) => item}
      renderItem={({ item }) => (
        <Pressable style={styles.row} onPress={() => onStopSelected(item)}>
          <Text style={styles.rowTitle}>{item}</Text>
          <Text>▸</Text>
        </Pressable>
      )}
    />
  )
}
```

function ScheduleScreen({ db, stop }: {

## Главный компонент

```tsx
export default function App() {
  const [db, setDb] = useState<SQLite.SQLiteDatabase | null>(null)
  const [selectedStop, setSelectedStop] = useState<string | null>(null)

  useEffect(() => {
    initDatabase().then(setDb)
  }, [])

      ) : (
        <StopsList db={db} onStopSelected={setSelectedStop} />

```

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useEffect, useState } from 'react';
import { ActivityIndicator, Button, FlatList, Pressable, StyleSheet, Text, View } from 'react-native';
import * as SQLite from 'expo-sqlite';
import scheduleData from './assets/schedule.json';

type ScheduleEntry = { id: number; stop: string; time: string }

async function initDatabase(): Promise<SQLite.SQLiteDatabase> {
  const db = await SQLite.openDatabaseAsync('bus-schedule.db')
  await db.execAsync(`
    CREATE TABLE IF NOT EXISTS schedule (
      id INTEGER PRIMARY KEY,
      stop TEXT NOT NULL,
      time TEXT NOT NULL
    )
  `)
  const count = await db.getFirstAsync<{ count: number }>(
    'SELECT COUNT(*) as count FROM schedule'
  )
  if (count && count.count === 0) {
    for (const entry of scheduleData) {
      await db.runAsync(
        'INSERT INTO schedule (id, stop, time) VALUES (?, ?, ?)',
        entry.id, entry.stop, entry.time
      )
    }
  }
  return db
}

function StopsList({ db, onSelect }: { db: SQLite.SQLiteDatabase; onSelect: (s: string) => void }) {
  const [stops, setStops] = useState<string[]>([])
  useEffect(() => {
    db.getAllAsync<{ stop: string }>('SELECT DISTINCT stop FROM schedule ORDER BY stop').then((rows) =>
      setStops(rows.map((r) => r.stop))
    )
  }, [])
  return (
    <FlatList
      data={stops}
      keyExtractor={(s) => s}
      renderItem={({ item }) => (
        <Pressable style={styles.row} onPress={() => onSelect(item)}>
          <Text style={styles.rowTitle}>{item}</Text>
          <Text>▸</Text>
        </Pressable>
      )}
    />
  )
}

function ScheduleScreen({ db, stop }: { db: SQLite.SQLiteDatabase; stop: string }) {
  const [entries, setEntries] = useState<ScheduleEntry[]>([])
  useEffect(() => {
    db.getAllAsync<ScheduleEntry>('SELECT * FROM schedule WHERE stop = ? ORDER BY time', stop).then(setEntries)
  }, [])
  return (
    <FlatList
      data={entries}
      keyExtractor={(item) => String(item.id)}
      renderItem={({ item }) => (
        <View style={styles.row}>
          <Text style={styles.time}>{item.time}</Text>
          <Text>{item.stop}</Text>
        </View>
      )}
    />
  )
}

export default function App() {
  const [db, setDb] = useState<SQLite.SQLiteDatabase | null>(null)
  const [selectedStop, setSelectedStop] = useState<string | null>(null)

  useEffect(() => { initDatabase().then(setDb) }, [])

  if (!db) return <ActivityIndicator size="large" style={styles.center} />

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Расписание автобусов</Text>
      {selectedStop ? (
        <>
          <Button title="← Все остановки" onPress={() => setSelectedStop(null)} />
          <Text style={styles.subtitle}>{selectedStop}</Text>
          <ScheduleScreen db={db} stop={selectedStop} />
        </>
      ) : (
        <StopsList db={db} onSelect={setSelectedStop} />
      )}
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 16, paddingTop: 60 },
  center: { flex: 1, alignItems: 'center', justifyContent: 'center' },
  title: { fontSize: 22, fontWeight: 'bold', marginBottom: 16 },
  subtitle: { fontSize: 18, marginVertical: 8 },
  row: { flexDirection: 'row', justifyContent: 'space-between', padding: 16, borderBottomWidth: 1, borderBottomColor: '#EEE' },
  rowTitle: { fontSize: 16 },
  time: { fontWeight: 'bold', marginRight: 16 },
})
```

## Итог

- JSON-данные загружаются в SQLite при первом запуске.
- `SELECT DISTINCT` получает уникальные остановки.
- `WHERE stop = ?` фильтрует расписание по выбранной остановке.
- Приложение обновляется динамически без перезапуска.
