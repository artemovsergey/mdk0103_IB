# Лекция 14. SQL и базы данных

Многие приложения хранят данные на устройстве: будильники, контакты, заметки. **SQLite** — реляционная база данных, встроенная в мобильные платформы. В React Native доступ к ней предоставляет пакет **expo-sqlite**.

### Необходимые условия

- Умение работать с TypeScript.
- Базовое понимание структур данных (массивы, объекты).

### Что вы узнаете

- Что такое реляционная база данных и таблица.
- Как выполнять SQL-запросы: `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`.
- Как работать с SQLite в React Native через `expo-sqlite`.

### Что вы создадите

Приложение с локальной базой данных для хранения и чтения данных.

## Что такое база данных

База данных — это организованная коллекция структурированной информации. Реляционная база данных хранит данные в **таблицах** (как листы в таблице).

## Что такое SQL

**SQL** (Structured Query Language) — язык запросов для реляционных баз данных. Основные операции:

| Операция | SQL | Пример |
|---|---|---|
| Создание таблицы | `CREATE TABLE` | `CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT, age INTEGER)` |
| Добавление строки | `INSERT INTO` | `INSERT INTO users (name, age) VALUES ('Анна', 25)` |
| Чтение данных | `SELECT` | `SELECT * FROM users WHERE age > 20` |
| Обновление | `UPDATE` | `UPDATE users SET age = 26 WHERE name = 'Анна'` |
| Удаление | `DELETE` | `DELETE FROM users WHERE id = 1` |

## SQLite в React Native

Установите пакет:

```
npx expo install expo-sqlite
```

### Открытие базы

```tsx
import * as SQLite from 'expo-sqlite'

const db = await SQLite.openDatabaseAsync('app.db')
```

### Создание таблицы

```tsx
await db.execAsync(`
  CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    age INTEGER NOT NULL
  )
`)
```

### Вставка данных

```tsx
await db.runAsync(
  'INSERT INTO users (name, age) VALUES (?, ?)',
  'Иван', 30
)
```

Символы `?` — это **параметризованные запросы**. Они защищают от SQL-инъекций.

### Чтение данных

```tsx
const rows = await db.getAllAsync('SELECT * FROM users')
// rows: [{ id: 1, name: 'Иван', age: 30 }, ...]
```

### Обновление и удаление

```tsx
await db.runAsync('UPDATE users SET age = ? WHERE id = ?', 31, 1)
await db.runAsync('DELETE FROM users WHERE id = ?', 1)
```

## Полный пример

```tsx
import { useEffect, useState } from 'react'
import { FlatList, StyleSheet, Text, TextInput, View, Button } from 'react-native'
import * as SQLite from 'expo-sqlite'

type User = { id: number; name: string; age: number }

let db: SQLite.SQLiteDatabase

export default function App() {
  const [users, setUsers] = useState<User[]>([])
  const [name, setName] = useState('')
  const [age, setAge] = useState('')

  useEffect(() => {
    ;(async () => {
      db = await SQLite.openDatabaseAsync('app.db')
      await db.execAsync(`
        CREATE TABLE IF NOT EXISTS users (
          id INTEGER PRIMARY KEY AUTOINCREMENT,
          name TEXT NOT NULL,
          age INTEGER NOT NULL
        )
      `)
      await loadUsers()
    })()
  }, [])

  async function loadUsers() {
    const rows = await db.getAllAsync<User>('SELECT * FROM users')
    setUsers(rows)
  }

  async function addUser() {
    if (!name || !age) return
    await db.runAsync('INSERT INTO users (name, age) VALUES (?, ?)', name, parseInt(age))
    setName('')
    setAge('')
    await loadUsers()
  }

  async function deleteUser(id: number) {
    await db.runAsync('DELETE FROM users WHERE id = ?', id)
    await loadUsers()
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>База данных SQLite</Text>

      <TextInput style={styles.input} value={name} onChangeText={setName} placeholder="Имя" />
      <TextInput style={styles.input} value={age} onChangeText={setAge} placeholder="Возраст" keyboardType="numeric" />
      <Button title="Добавить" onPress={addUser} />

      <FlatList
        data={users}
        keyExtractor={(item) => String(item.id)}
        renderItem={({ item }) => (
          <View style={styles.row}>
            <Text>{item.name}, {item.age} лет</Text>
            <Button title="Удалить" color="red" onPress={() => deleteUser(item.id)} />
          </View>
        )}
      />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 24, paddingTop: 60 },
  title: { fontSize: 22, fontWeight: 'bold', marginBottom: 16 },
  input: { borderWidth: 1, borderColor: '#CCC', borderRadius: 8, padding: 12, marginBottom: 12 },
  row: { flexDirection: 'row', justifyContent: 'space-between', padding: 12, borderBottomWidth: 1, borderBottomColor: '#EEE' },
})
```

## Резюме

- SQL — язык для реляционных баз данных.
- Таблица состоит из столбцов и строк.
- `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE` — основные операции.
- `expo-sqlite` позволяет работать с SQLite в React Native.
