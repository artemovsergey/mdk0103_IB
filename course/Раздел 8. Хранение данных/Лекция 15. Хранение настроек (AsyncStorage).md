# Лекция 15. Хранение настроек (AsyncStorage)

SQL и SQLite — мощный инструмент для структурированных данных. Но когда нужно сохранить пару простых настроек (тема, язык, порядок сортировки), реляционная база данных избыточна. Для этого существует **хранилище ключ-значение**.

Для таких случаев существует **хранилище ключ-значение**: данные сохраняются парами «ключ — значение» и восстанавливаются при следующем запуске. В React Native для этого используется **AsyncStorage**.

### Пререквизиты

- Умение работать с `useState` и `useEffect`.
- Знание промисов и `async`/`await`.

### Что вы узнаете

- Что такое хранилище ключ-значение.
- Как сохранять и читать настройки через `AsyncStorage`.
- Как обновлять UI после чтения сохранённых значений.

### Что вы создадите

Приложение **Dessert Release**, которое сохраняет выбор макета (список / сетка) и восстанавливает его при перезапуске.

## Установка

```
npx expo install @react-native-async-storage/async-storage
```

## Основные методы

```tsx
import AsyncStorage from '@react-native-async-storage/async-storage'

// Сохранить
await AsyncStorage.setItem('theme', 'dark')

// Прочитать
const theme = await AsyncStorage.getItem('theme') // 'dark' | null

// Удалить
await AsyncStorage.removeItem('theme')

// Очистить всё
await AsyncStorage.clear()
```

`AsyncStorage` хранит строки. Если нужно сохранить объект — сериализуйте в JSON:

```tsx
await AsyncStorage.setItem('user', JSON.stringify({ name: 'Иван', age: 30 }))
const json = await AsyncStorage.getItem('user')
const user = json ? JSON.parse(json) : null
```

## Приложение Dessert Release

Приложение показывает список релизов Android. Иконка переключает макет между списком и сеткой. Выбор макета сохраняется:

```tsx
import { useEffect, useState } from 'react'
import { FlatList, StyleSheet, Text, View, TouchableOpacity } from 'react-native'
import AsyncStorage from '@react-native-async-storage/async-storage'

const releases = [
  { id: '1', name: 'Android 14', year: 2023 },
  { id: '2', name: 'Android 13', year: 2022 },
  { id: '3', name: 'Android 12', year: 2021 },
]

type Layout = 'list' | 'grid'

const STORAGE_KEY = 'layout_preference'

export default function App() {
  const [layout, setLayout] = useState<Layout>('list')
  const [ready, setReady] = useState(false)

  useEffect(() => {
    AsyncStorage.getItem(STORAGE_KEY).then((value) => {
      if (value === 'list' || value === 'grid') {
        setLayout(value)
      }
      setReady(true)
    })
  }, [])

  async function toggleLayout() {
    const next: Layout = layout === 'list' ? 'grid' : 'list'
    setLayout(next)
    await AsyncStorage.setItem(STORAGE_KEY, next)
  }

  if (!ready) return null

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.title}>Dessert Release</Text>
        <TouchableOpacity onPress={toggleLayout}>
          <Text style={styles.toggle}>{layout === 'list' ? '⊞' : '☰'}</Text>
        </TouchableOpacity>
      </View>

      <FlatList
        data={releases}
        keyExtractor={(item) => item.id}
        numColumns={layout === 'grid' ? 2 : 1}
        key={layout}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => (
          <View style={[styles.card, layout === 'grid' && styles.gridCard]}>
            <Text style={styles.cardTitle}>{item.name}</Text>
            <Text>Год: {item.year}</Text>
          </View>
        )}
      />
    </View>
  )
}

const styles = StyleSheet.create({
  container: { flex: 1, paddingTop: 60 },
  header: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 16 },
  title: { fontSize: 22, fontWeight: 'bold' },
  toggle: { fontSize: 28 },
  list: { padding: 16 },
  card: { borderWidth: 1, borderColor: '#DDD', borderRadius: 8, padding: 16, marginBottom: 12 },
  gridCard: { flex: 1, margin: 6 },
  cardTitle: { fontSize: 16, fontWeight: 'bold', marginBottom: 4 },
})
```

## Как это работает

1. При запуске `useEffect` читает сохранённое значение из `AsyncStorage`.
2. Если значение есть, оно устанавливается в состояние.
3. При нажатии на иконку `toggleLayout` меняется состояние и сохраняется новое значение.
4. При следующем запуске приложение «помнит» выбор пользователя.

## Когда использовать AsyncStorage, а когда SQLite

| Критерий | AsyncStorage | SQLite |
|---|---|---|
| Тип данных | Простые настроек, строки | Структурированные таблицы |
| Запросы | GET/SET по ключу | SQL-запросы с фильтрацией |
| Объём | Малый | Большой |
| Сложность | Простая | Высокая |

## Резюме

- `AsyncStorage` — простое хранилище ключ-значение для данных приложения.
- Данные сохраняются между перезапусками.
- Используйте для настроек и простых данных; для реляционных данных — SQLite.
