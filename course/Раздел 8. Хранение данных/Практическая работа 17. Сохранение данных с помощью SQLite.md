# Практическая работа 17. Сохранение данных с помощью SQLite

В большинстве приложений есть данные, которые нужно сохранять: плейлисты, списки дел, записи расходов. В этой работе вы создадите приложение **Inventory**, которое хранит предметы в базе данных SQLite.

### Пререквизиты

- Лекция 14 «SQL и базы данных».
- Умение работать с `useState`, `useEffect` и `TextInput`.

### Что вы узнаете

- Как создать таблицу и DAO (Data Access Object) для SQLite.
- Как добавлять и сохранять данные.
- Как выстроить слой данных для приложения.

### Что вы создадите

Приложение Inventory, где пользователь может добавлять предметы (название, количество, цена).

npx expo install expo-sqlite

## Создание базы данных

```tsx
import * as SQLite from 'expo-sqlite'

export async function getDatabase(): Promise<SQLite.SQLiteDatabase> {
  const db = await SQLite.openDatabaseAsync('inventory.db')
  await db.execAsync(`
    CREATE TABLE IF NOT EXISTS items (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      quantity INTEGER NOT NULL,
      price REAL NOT NULL
    )
  `)
  return db
}
```

## DAO — слой данных

Вынесем операции с базой в отдельный модуль:

```tsx
export type Item = {
  id: number
  name: string
  quantity: number
  price: number
}

export async function insertItem(
  db: SQLite.SQLiteDatabase,
  name: string,
  quantity: number,
  price: number
): Promise<void> {
  await db.runAsync(
    'INSERT INTO items (name, quantity, price) VALUES (?, ?, ?)',
    name, quantity, price
  )
}

export async function getAllItems(db: SQLite.SQLiteDatabase): Promise<Item[]> {
  return await db.getAllAsync<Item>('SELECT * FROM items')
}
```

## Экран добавления

```tsx
function AddItemForm({ onItemAdded }: { onItemAdded: () => void }) {
  const [name, setName] = useState('')
  const [quantity, setQuantity] = useState('')
  const [price, setPrice] = useState('')

  async function handleAdd() {
    const db = await getDatabase()
    await insertItem(db, name, parseInt(quantity) || 0, parseFloat(price) || 0)
    setName('')
    setQuantity('')
    setPrice('')
    onItemAdded()
  }

  return (
    <View style={styles.form}>
      <TextInput style={styles.input} placeholder="Название" value={name} onChangeText={setName} />
      <TextInput style={styles.input} placeholder="Количество" value={quantity} onChangeText={setQuantity} keyboardType="numeric" />
      <TextInput style={styles.input} placeholder="Цена" value={price} onChangeText={setPrice} keyboardType="numeric" />
      <Button title="Добавить" onPress={handleAdd} />
    </View>
  )
}
```

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useEffect, useState } from 'react';
import { Button, FlatList, StyleSheet, Text, TextInput, View } from 'react-native';
import * as SQLite from 'expo-sqlite';

type Item = { id: number; name: string; quantity: number; price: number }

async function getDb() {
  const db = await SQLite.openDatabaseAsync('inventory.db')
  await db.execAsync(`
    CREATE TABLE IF NOT EXISTS items (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      quantity INTEGER NOT NULL,
      price REAL NOT NULL
    )
  `)
  return db
}

function AddItemForm({ onAdded }: { onAdded: () => void }) {
  const [name, setName] = useState('')
  const [quantity, setQuantity] = useState('')
  const [price, setPrice] = useState('')

  async function add() {
    const db = await getDb()
    await db.runAsync(
      'INSERT INTO items (name, quantity, price) VALUES (?, ?, ?)',
      name, parseInt(quantity) || 0, parseFloat(price) || 0
    )
    setName(''); setQuantity(''); setPrice('')
    onAdded()
  }

  return (
    <View style={styles.form}>
      <TextInput style={styles.input} placeholder="Название" value={name} onChangeText={setName} />
      <TextInput style={styles.input} placeholder="Количество" value={quantity} onChangeText={setQuantity} keyboardType="numeric" />
      <TextInput style={styles.input} placeholder="Цена" value={price} onChangeText={setPrice} keyboardType="numeric" />
      <Button title="Добавить" onPress={add} />
    </View>
  )
}

export default function App() {
  const [items, setItems] = useState<Item[]>([])

  async function loadItems() {
    const db = await getDb()
    setItems(await db.getAllAsync<Item>('SELECT * FROM items'))
  }

  useEffect(() => { loadItems() }, [])

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Инвентарь</Text>
      <AddItemForm onAdded={loadItems} />
      <FlatList
        data={items}
        keyExtractor={(item) => String(item.id)}
        renderItem={({ item }) => (
          <View style={styles.row}>
            <Text>{item.name}</Text>
            <Text>×{item.quantity}</Text>
            <Text>{item.price} ₽</Text>
          </View>
        )}
      />
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 24, paddingTop: 60 },
  title: { fontSize: 22, fontWeight: 'bold', marginBottom: 16 },
  form: { marginBottom: 24 },
  input: { borderWidth: 1, borderColor: '#CCC', borderRadius: 8, padding: 12, marginBottom: 12 },
  row: { flexDirection: 'row', justifyContent: 'space-between', padding: 12, borderBottomWidth: 1, borderBottomColor: '#EEE' },
})
```

## Итог

- SQLite хранит структурированные данные на устройстве.
- DAO-модуль скрывает SQL-запросы от UI.
- Параметризованные запросы защищают от SQL-инъекций.
