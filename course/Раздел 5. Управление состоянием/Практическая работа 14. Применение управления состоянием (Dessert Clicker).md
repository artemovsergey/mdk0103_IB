# Практическая работа 14. Вынос логики приложения в хук (Dessert Clicker)

Приложение `Dessert Clicker` работает с состоянием прямо в компоненте. В этом упражнении вы вынесете состояние, данные и логику из компонента в **собственный хук**.

Абстрагирование логики приложения от представления — современная практика разработки. Она даёт преимущества:

- Код становится читабельнее для других разработчиков.
- Логику можно тестировать отдельно от интерфейса.
- Несколько разработчиков могут работать над приложением параллельно.

### Что вам понадобится

- Код решения приложения `Dessert Clicker`.
- Лекция 10 «Управление состоянием».

### Что вы создадите

Вы улучшите архитектуру приложения `Dessert Clicker`, вынеся данные и логику в хук `useDessertClicker`.

## Что делает приложение Dessert Clicker

Пользователь нажимает на десерт, получает доход, а каждые несколько десертов открывается новый вид десерта. Приложение хранит:

- текущий десерт;
- количество проданных десертов;
- общий доход;
- индекс текущего десерта.

## Шаг 1. Данные о десертах

```tsx
type Dessert = { id: string; name: string; price: number; image: any }

const desserts: Dessert[] = [
  { id: '1', name: 'Пончик', price: 2, image: require('./assets/donut.png') },
  { id: '2', name: 'Кекс', price: 3, image: require('./assets/cupcake.png') },
  { id: '3', name: 'Мороженое', price: 4, image: require('./assets/icecream.png') },
]

const DESSERTS_SOLD_TO_CHANGE = 5
```

## Шаг 2. Создайте хук

Перенесите всё состояние и логику в `useDessertClicker`:

```tsx
import { useState } from 'react'

export function useDessertClicker() {
  const [dessertIndex, setDessertIndex] = useState(0)
  const [revenue, setRevenue] = useState(0)
  const [amountSold, setAmountSold] = useState(0)

  const currentDessert = desserts[dessertIndex]

  function onDessertClicked() {
    setRevenue(revenue + currentDessert.price)
    setAmountSold(amountSold + 1)
    if (amountSold + 1 >= (dessertIndex + 1) * DESSERTS_SOLD_TO_CHANGE) {
      setDessertIndex((dessertIndex + 1) % desserts.length)
    }
  }

  return { currentDessert, revenue, amountSold, onDessertClicked }
}
```

## Шаг 3. Компонент использует хук

Компонент больше не хранит логику — он только отображает данные:

```tsx
function DessertClickerApp() {
  const { currentDessert, revenue, amountSold, onDessertClicked } = useDessertClicker()

  return (
    <View style={styles.container}>
      <Text style={styles.text}>Продано десертов: {amountSold}</Text>
      <Text style={styles.text}>Доход: {revenue} ₽</Text>

      <Pressable onPress={onDessertClicked}>
        <Text style={styles.dessert}>{currentDessert.name}</Text>
      </Pressable>
    </View>
  )
}
```

## Шаг 4. Разделение состояния и логики

Обратите внимание на принцип:

- **Состояние** (`dessertIndex`, `revenue`, `amountSold`) живёт в хуке.
- **Логика** (`onDessertClicked`) тоже в хуке.
- **Представление** (компонент) только рисует то, что вернул хук.

Такое разделение позволяет протестировать функцию расчёта дохода без запуска интерфейса.

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import { Pressable, StyleSheet, Text, View } from 'react-native';

type Dessert = { id: string; name: string; price: number }

const desserts: Dessert[] = [
  { id: '1', name: 'Пончик', price: 2 },
  { id: '2', name: 'Кекс', price: 3 },
  { id: '3', name: 'Мороженое', price: 4 },
]

const DESSERTS_SOLD_TO_CHANGE = 5

function useDessertClicker() {
  const [dessertIndex, setDessertIndex] = useState(0)
  const [revenue, setRevenue] = useState(0)
  const [amountSold, setAmountSold] = useState(0)

  const currentDessert = desserts[dessertIndex]

  function onDessertClicked() {
    setRevenue(revenue + currentDessert.price)
    setAmountSold(amountSold + 1)
    if (amountSold + 1 >= (dessertIndex + 1) * DESSERTS_SOLD_TO_CHANGE) {
      setDessertIndex((dessertIndex + 1) % desserts.length)
    }
  }

  return { currentDessert, revenue, amountSold, onDessertClicked }
}

function DessertClickerApp() {
  const { currentDessert, revenue, amountSold, onDessertClicked } = useDessertClicker()

  return (
    <View style={styles.container}>
      <Text style={styles.text}>Продано десертов: {amountSold}</Text>
      <Text style={styles.text}>Доход: {revenue} ₽</Text>

      <Pressable style={styles.button} onPress={onDessertClicked}>
        <Text style={styles.dessert}>{currentDessert.name}</Text>
      </Pressable>
    </View>
  )
}

export default function App() {
  return (
    <>
      <DessertClickerApp />
      <StatusBar style="auto" />
    </>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
    padding: 24,
  },
  text: { fontSize: 18, marginBottom: 8 },
  button: {
    marginTop: 24,
    padding: 24,
    backgroundColor: '#FFE0B2',
    borderRadius: 16,
  },
  dessert: { fontSize: 28, fontWeight: 'bold' },
})
```
