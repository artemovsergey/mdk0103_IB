# Лекция 10. Управление состоянием и архитектура приложения

В предыдущих работах вы управляли состоянием прямо внутри компонентов с помощью `useState`. Когда приложение растёт, хранить данные и логику в компонентах становится неудобно: компоненты разрастаются, логику трудно тестировать и переиспользовать.

В этом уроке вы узнаете, как выносить данные и логику из представления — в **хуки** и **контекст**.

### Пререквизиты

- Знание TypeScript: функции, объекты, массивы.
- Умение создавать состояние через `useState`.
- Базовое представление о компонентах.

### Что вы узнаете

- Что такое архитектура приложения и зачем разделять логику и представление.
- Как создать собственный хук для логики приложения.
- Как использовать `useReducer` для сложного состояния.
- Как передавать состояние вглубь дерева через React Context.

### Что вы создадите

Игровое приложение **Unscramble**, в котором пользователь угадывает зашифрованные слова.

## Какие проблемы решает вынос логики

Представьте, что вся игра Unscramble написана в одном компоненте:

```tsx
function UnscrambleApp() {
  const [currentWord, setCurrentWord] = useState('scrambleun')
  const [score, setScore] = useState(0)
  const [wordCount, setWordCount] = useState(0)
  const [isGuessed, setIsGuessed] = useState(false)
  // ... ещё десяток состояний и обработчиков
}
```

Компонент становится большим и делает слишком много. Тестировать игру (например, начисление очков) без интерфейса невозможно.

Решение — вынести состояние и логику в отдельный **хук**, а компонент оставить только для отображения.

## Собственный хук: useUnscrambleGame

Собственный хук — это функция, имя которой начинается с `use` и которая использует другие хуки. Вынесем всю логику игры:

```tsx
import { useState } from 'react'

const WORDS = ['android', 'program', 'mobile', 'react', 'native']

function shuffle(word: string): string {
  return word.split('').sort(() => Math.random() - 0.5).join('')
}

export function useUnscrambleGame() {
  const [currentWord, setCurrentWord] = useState(WORDS[0])
  const [scrambledWord, setScrambledWord] = useState(shuffle(WORDS[0]))
  const [isGuessed, setIsGuessed] = useState(false)
  const [score, setScore] = useState(0)
  const [wordCount, setWordCount] = useState(0)

  function submitGuess(guess: string) {
    if (guess.equalsIgnoreCase(currentWord)) {
      setScore(score + 1)
      setIsGuessed(true)
    }
  }
  // ...
  return { currentWord, scrambledWord, isGuessed, score, wordCount, submitGuess }
}
```

> В TypeScript нет метода `.equalsIgnoreCase`. Используйте `guess.toLowerCase() === currentWord.toLowerCase()`.

Теперь компонент становится простым:

```tsx
function UnscrambleApp() {
  const game = useUnscrambleGame()
  return (
    <View>
      <Text>{game.scrambledWord}</Text>
      {/* ... */}
    </View>
  )
}
```

## Более сложное состояние: useReducer

Когда состояний много и они связаны, удобнее `useReducer`. Он собирает все изменения состояния в одну функцию-редьюсер:

```tsx
type GameState = {
  currentWord: string
  scrambledWord: string
  isGuessed: boolean
  score: number
  wordCount: number
}

type GameAction =
  | { type: 'SUBMIT_GUESS'; guess: string }
  | { type: 'SKIP_WORD' }
  | { type: 'NEXT_WORD' }

function gameReducer(state: GameState, action: GameAction): GameState {
  switch (action.type) {
    case 'SUBMIT_GUESS':
      return action.guess.toLowerCase() === state.currentWord.toLowerCase()
        ? { ...state, score: state.score + 1, isGuessed: true }
        : state
    case 'SKIP_WORD':
      return { ...state, isGuessed: true }
    case 'NEXT_WORD':
      return startNewWord(state)
    default:
      return state
  }
}
```

Хук создаёт редьюсер:

```tsx
import { useReducer } from 'react'

export function useUnscrambleGame() {
  const [state, dispatch] = useReducer(gameReducer, initialState)
  return {
    ...state,
    submitGuess: (guess: string) => dispatch({ type: 'SUBMIT_GUESS', guess }),
    skipWord: () => dispatch({ type: 'SKIP_WORD' }),
  }
}
```

**Преимущества `useReducer`:**

- Вся логика изменения состояния в одном месте.
- Редьюсер — чистая функция, её легко тестировать.
- Действия описывают, что произошло, а не как меняется состояние.

## Передача состояния через Context

Когда состояние нужно многим компонентам на разных уровнях, используют **React Context**, чтобы не передавать props через каждый уровень:

```tsx
import { createContext, useContext } from 'react'

const GameContext = createContext<ReturnType<typeof useUnscrambleGame> | null>(null)

export function GameProvider({ children }: { children: React.ReactNode }) {
  const game = useUnscrambleGame()
  return <GameContext.Provider value={game}>{children}</GameContext.Provider>
}

export function useGame() {
  const ctx = useContext(GameContext)
  if (!ctx) throw new Error('useGame must be used within GameProvider')
  return ctx
}
```

Теперь любой компонент внутри `GameProvider` может получить состояние:

```tsx
function ScoreBoard() {
  const { score, wordCount } = useGame()
  return <Text>Очки: {score} / Слов: {wordCount}</Text>
}
```

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { createContext, useContext, useReducer, useState } from 'react';
import { Button, StyleSheet, Text, TextInput, View } from 'react-native';

const WORDS = ['android', 'program', 'mobile', 'react', 'native']
const MAX_WORDS = 10

function shuffle(word: string): string {
  return word.split('').sort(() => Math.random() - 0.5).join('')
}

type GameState = {
  currentWord: string
  scrambledWord: string
  isGuessed: boolean
  score: number
  wordCount: number
}

type GameAction =
  | { type: 'SUBMIT_GUESS'; guess: string }
  | { type: 'SKIP_WORD' }
  | { type: 'NEXT_WORD' }

const initialState: GameState = {
  currentWord: WORDS[0],
  scrambledWord: shuffle(WORDS[0]),
  isGuessed: false,
  score: 0,
  wordCount: 1,
}

function gameReducer(state: GameState, action: GameAction): GameState {
  switch (action.type) {
    case 'SUBMIT_GUESS':
      return action.guess.toLowerCase() === state.currentWord.toLowerCase()
        ? { ...state, score: state.score + 1, isGuessed: true }
        : state
    case 'SKIP_WORD':
      return { ...state, isGuessed: true }
    case 'NEXT_WORD': {
      if (state.wordCount >= MAX_WORDS) return state
      const nextWord = WORDS[state.wordCount % WORDS.length]
      return {
        ...state,
        currentWord: nextWord,
        scrambledWord: shuffle(nextWord),
        isGuessed: false,
        wordCount: state.wordCount + 1,
      }
    }
    default:
      return state
  }
}

function useUnscrambleGame() {
  const [state, dispatch] = useReducer(gameReducer, initialState)
  return {
    ...state,
    submitGuess: (guess: string) => dispatch({ type: 'SUBMIT_GUESS', guess }),
    skipWord: () => dispatch({ type: 'SKIP_WORD' }),
    nextWord: () => dispatch({ type: 'NEXT_WORD' }),
  }
}

const GameContext = createContext<ReturnType<typeof useUnscrambleGame> | null>(null)

function GameProvider({ children }: { children: React.ReactNode }) {
  const game = useUnscrambleGame()
  return <GameContext.Provider value={game}>{children}</GameContext.Provider>
}

function useGame() {
  const ctx = useContext(GameContext)
  if (!ctx) throw new Error('useGame must be used within GameProvider')
  return ctx
}

function UnscrambleApp() {
  const { scrambledWord, isGuessed, nextWord, skipWord, submitGuess } = useGame()
  const [guess, setGuess] = useState('')

  return (
    <View style={styles.container}>
      <Text style={styles.word}>{scrambledWord}</Text>

      <TextInput
        style={styles.input}
        value={guess}
        onChangeText={setGuess}
        placeholder="Ваш ответ"
        editable={!isGuessed}
      />

      <Button title="Проверить" onPress={() => submitGuess(guess)} />

      {isGuessed && <Button title="Следующее слово" onPress={nextWord} />}
      {!isGuessed && <Button title="Пропустить" onPress={skipWord} />}
    </View>
  )
}

export default function App() {
  return (
    <GameProvider>
      <UnscrambleApp />
      <StatusBar style="auto" />
    </GameProvider>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
    padding: 40,
  },
  word: { fontSize: 32, fontWeight: 'bold', marginBottom: 32 },
  input: {
    width: '100%',
    borderWidth: 1,
    borderColor: '#CCC',
    borderRadius: 8,
    padding: 12,
    marginBottom: 16,
  },
})
```

## Резюме

- Архитектура — это структура приложения; логику отделяют от представления.
- Собственный хук (`use...`) хранит и логику, и состояние.
- `useReducer` подходит для сложного связанного состояния.
- `Context` передаёт состояние вглубь дерева без «прокидывания» props.
