# Практическая работа 11. Калькулятор чаевых

В этой работе вы продолжите приложение **Tip Time** из лекции 8 и сделаете его интерактивным: добавите поле для процента чаевых, переключатель округления и удобный ввод с клавиатуры.

### Пререквизиты

- Лекция 8 «Работа с состоянием».
- Умение создавать состояние через `useState` и поднимать его вверх.
- Знание управляемых компонентов `TextInput`.

### Что вы узнаете

- Как настроить виртуальную клавиатуру (`keyboardType`, `returnKeyType`).
- Как использовать компонент `Switch`.
- Как добавить ведущие иконки в текстовые поля.

### Что вы создадите

Приложение `Tip Time`, которое рассчитывает сумму чаевых по введённой сумме счёта и проценту и умеет округлять результат.

## Обзор стартового приложения

В приложении из лекции 8 есть поле «Сумма счёта», но процент чаевых жёстко задан как 15%. Добавим поле для процента и округление.

## Шаг 1. Добавьте поле процента чаевых

Вынесем текстовое поле в переиспользуемый компонент и добавим второе поле — для процента:

```tsx
function EditNumberField({
  label,
  value,
  onValueChanged,
  imeAction,
  keyboard,
}: {
  label: string
  value: string
  onValueChanged: (text: string) => void
  imeAction: 'next' | 'done'
  keyboard: 'numeric' | 'decimal-pad'
}) {
  return (
    <View style={styles.field}>
      <Text style={styles.label}>{label}</Text>
      <TextInput
        style={styles.input}
        value={value}
        onChangeText={onValueChanged}
        keyboardType={keyboard}
        returnKeyType={imeAction}
      />
    </View>
  )
}
```

Пояснения:

- `keyboardType="decimal-pad"` — цифровая клавиатура с десятичным разделителем (для суммы счёта).
- `keyboardType="numeric"` — целочисленная клавиатура (для процента).
- `returnKeyType="next"` и `"done"` — надпись на кнопке действия клавиатуры («Далее» / «Готово»).

## Шаг 2. Состояние в App

```tsx
export default function App() {
  const [amountInput, setAmountInput] = useState("")
  const [tipPercentInput, setTipPercentInput] = useState("15")

  const amount = parseFloat(amountInput) || 0
  const tipPercent = parseFloat(tipPercentInput) || 0
  const tip = calculateTip(amount, tipPercent)

  return (
    <ScrollView contentContainerStyle={styles.container}>
      <Text style={styles.title}>Рассчитать чаевые</Text>

      <Text style={styles.result}>Сумма чаевых: {tip.toFixed(2)} ₽</Text>

      <EditNumberField
        label="Сумма счёта"
        value={amountInput}
        onValueChanged={setAmountInput}
        keyboard="decimal-pad"
        imeAction="next"
      />
      <EditNumberField
        label="Процент чаевых"
        value={tipPercentInput}
        onValueChanged={setTipPercentInput}
        keyboard="numeric"
        imeAction="done"
      />
    </ScrollView>
  )
}
```

## Шаг 3. Автоматическое обновление

Как только меняется `amountInput` или `tipPercentInput`, React перерисовывает компонент, и значение `tip` пересчитывается:

```tsx
function calculateTip(amount: number, tipPercent: number = 15): number {
  return (tipPercent / 100) * amount
}
```

## Шаг 4. Переключатель округления

В оригинальном приложении есть `Switch` для округления суммы чаевых до целого. Добавим состояние и сам переключатель:

```tsx
const [roundUp, setRoundUp] = useState(false)

<View style={styles.switchRow}>
  <Text style={styles.label}>Округлить сумму чаевых</Text>
  <Switch value={roundUp} onValueChange={setRoundUp} />
</View>
```

Затем учтём его в расчёте:

```tsx
const tip = roundUp ? Math.ceil(rawTip) : rawTip

<Text style={styles.result}>
  Сумма чаевых: {tip.toFixed(2)} ₽
</Text>
```

## Шаг 5. Прокрутка в альбомной ориентации

На маленьких экранах контент может не помещаться. Оберните содержимое в `ScrollView` (см. `App` выше) и задайте:

```tsx
contentContainerStyle={styles.container}
```

```tsx
container: {
  flexGrow: 1,
  alignItems: 'center',
  justifyContent: 'center',
  padding: 40,
},
```

`flexGrow: 1` позволяет контенту центрироваться, когда он меньше экрана, но прокручиваться, когда не помещается.

## Шаг 6. Ведущие иконки (по желанию)

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import {
  ScrollView,
  StyleSheet,
  Switch,
  Text,
  TextInput,
  View,
} from 'react-native';

function calculateTip(amount: number, tipPercent: number = 15): number {
  return (tipPercent / 100) * amount
}

function EditNumberField({
  label,
  value,
  onValueChanged,
  imeAction,
  keyboard,
}: {
  label: string
  value: string
  onValueChanged: (text: string) => void
  imeAction: 'next' | 'done'
  keyboard: 'numeric' | 'decimal-pad'
}) {
  return (
    <View style={styles.field}>
      <Text style={styles.label}>{label}</Text>
      <TextInput
        style={styles.input}
        value={value}
        onChangeText={onValueChanged}
        keyboardType={keyboard}
        returnKeyType={imeAction}
      />
    </View>
  )
}

export default function App() {
  const [amountInput, setAmountInput] = useState("")
  const [tipPercentInput, setTipPercentInput] = useState("15")
  const [roundUp, setRoundUp] = useState(false)

  const amount = parseFloat(amountInput) || 0
  const tipPercent = parseFloat(tipPercentInput) || 0
  const rawTip = calculateTip(amount, tipPercent)
  const tip = roundUp ? Math.ceil(rawTip) : rawTip

  return (
    <ScrollView contentContainerStyle={styles.container}>
      <Text style={styles.title}>Рассчитать чаевые</Text>
      <Text style={styles.result}>Сумма чаевых: {tip.toFixed(2)} ₽</Text>

      <EditNumberField
        label="Сумма счёта"
        value={amountInput}
        onValueChanged={setAmountInput}
        keyboard="decimal-pad"
        imeAction="next"
      />
      <EditNumberField
        label="Процент чаевых"
        value={tipPercentInput}
        onValueChanged={setTipPercentInput}
        keyboard="numeric"
        imeAction="done"
      />

      <View style={styles.switchRow}>
        <Text style={styles.label}>Округлить сумму чаевых</Text>
        <Switch value={roundUp} onValueChange={setRoundUp} />
      </View>

      <StatusBar style="auto" />
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: {
    flexGrow: 1,
    alignItems: 'center',
    justifyContent: 'center',
    padding: 40,
    backgroundColor: '#F5F5F5',
  },
  title: { fontSize: 20, marginBottom: 16 },
  field: { width: '100%', marginBottom: 16 },
  label: { fontSize: 16, marginBottom: 8 },
  input: {
    borderWidth: 1,
    borderColor: '#CCCCCC',
    borderRadius: 8,
    padding: 12,
    fontSize: 16,
    backgroundColor: '#FFFFFF',
  },
  switchRow: {
    width: '100%',
    flexDirection: 'row',
    justifyContent: 'space-between',
    alignItems: 'center',
  },
  result: { fontSize: 24, fontWeight: 'bold', marginBottom: 24 },
})
```
