# Лекция 8. Работа с состоянием в React Native

По своей сути **состояние** в приложении — это любое значение, которое может изменяться со временем. Это очень широкое определение: оно включает и текст в поле ввода, и то, нажата ли кнопка, и загруженные ли данные.

Все приложения отображают состояние пользователю. Примеры состояния:

- Сообщение об ошибке при отсутствии сети.
- Текст, введённый в форму регистрации.
- Нажата или не нажата кнопка.

На этом занятии вы научитесь работать с состоянием в React Native, создав интерактивный калькулятор чаевых **Tip Time**.

### Что вы узнаете

- Как хранить состояние с помощью хука `useState`.
- Как создать управляемое текстовое поле `TextInput`.
- Как поднимать состояние вверх (state lifting).

### Что вы создадите

Приложение **Tip Time**, которое рассчитывает сумму чаевых на основе введённой суммы счёта. Процент чаевых пока жёстко задан на 15%.

## Что такое состояние

Состояние — это данные, которые меняются во время работы приложения. Когда состояние меняется, React Native автоматически обновляет интерфейс, чтобы отобразить новое значение. Это называется **перерисовкой** (ререндером).

## Хук useState

Для хранения состояния в функциональном компоненте используется хук **`useState`**:

```tsx
import { useState } from 'react';

const [amountInput, setAmountInput] = useState("")
```

- `amountInput` — текущее значение состояния.
- `setAmountInput` — функция для его изменения.
- `useState("")` — начальное значение (пустая строка).

Когда вызывается `setAmountInput(новое_значение)`, компонент перерисовывается, и интерфейс показывает новое значение.

## Управляемое текстовое поле

Текстовое поле в React Native создаётся компонентом **`TextInput`**. Чтобы оно было **управляемым** (controlled), ему передают текущее значение (`value`) и обработчик изменения (`onChangeText`):

```tsx
<TextInput
  value={amountInput}
  onChangeText={setAmountInput}
/>
```

Связь работает так:

1. Пользователь вводит текст.
2. Вызывается `onChangeText` с новым текстом.
3. `setAmountInput` обновляет состояние.
4. Компонент перерисовывается, и `value` показывает новый текст.

## Приложение Tip Time

Соберём калькулятор чаевых. Создайте проект Expo и замените содержимое `App.tsx`:

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import { StyleSheet, Text, TextInput, View } from 'react-native';

function calculateTip(amount: number, tipPercent: number = 15): number {
  return (tipPercent / 100) * amount
}

export default function App() {
  const [amountInput, setAmountInput] = useState("")

  const amount = parseFloat(amountInput) || 0
  const tip = calculateTip(amount)

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Рассчитать чаевые</Text>

      <TextInput
        style={styles.input}
        value={amountInput}
        onChangeText={setAmountInput}
        placeholder="Сумма счёта"
        keyboardType="numeric"
      />

      <Text style={styles.result}>Сумма чаевых: {tip.toFixed(2)} ₽</Text>
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#F5F5F5',
    alignItems: 'center',
    justifyContent: 'center',
    padding: 40,
  },
  title: {
    fontSize: 20,
    marginBottom: 16,
  },
  input: {
    width: '100%',
    borderWidth: 1,
    borderColor: '#CCCCCC',
    borderRadius: 8,
    padding: 12,
    fontSize: 16,
    marginBottom: 24,
    backgroundColor: '#FFFFFF',
  },
  result: {
    fontSize: 24,
    fontWeight: 'bold',
  },
})
```

Разберём ключевые моменты:

- `parseFloat(amountInput) || 0` — преобразует строку в число. Если поле пустое или содержит не число, `parseFloat` вернёт `NaN`, и `|| 0` даст `0`.
- `keyboardType="numeric"` — открывает цифровую клавиатуру.
- `tip.toFixed(2)` — форматирует число с двумя знаками после запятой.

Введите сумму — сумма чаевых обновится автоматически.

## Поднятие состояния

Когда нескольким компонентам нужны одни и те же данные, состояние поднимают в их общего родителя. Это называется **поднятием состояния** (state lifting).

Например, вынесем текстовое поле в отдельный компонент `EditNumberField`, а состояние оставим в родителе:

```tsx
function EditNumberField({ value, onValueChanged }: { value: string; onValueChanged: (text: string) => void }) {
  return (
    <TextInput
      style={styles.input}
      value={value}
      onChangeText={onValueChanged}
      placeholder="Сумма счёта"
      keyboardType="numeric"
    />
  )
}
```

Родитель передаёт состояние и функцию его изменения как свойства (props):

```tsx
export default function App() {
  const [amountInput, setAmountInput] = useState("")

  return (
    <View style={styles.container}>
      <EditNumberField value={amountInput} onValueChanged={setAmountInput} />
      <Text>Сумма чаевых: {calculateTip(parseFloat(amountInput) || 0).toFixed(2)} ₽</Text>
    </View>
  )
}
```

Компонент `EditNumberField` не хранит своё состояние — он получает его от родителя. Такой компонент называется **без состояния** (stateless). Поднятие состояния делает компоненты переиспользуемыми.

## Резюме

- Состояние — это данные, которые меняются со временем.
- `useState` хранит состояние и возвращает значение и функцию его изменения.
- `TextInput` — управляемое поле: `value` + `onChangeText`.
- Поднятие состояния делает компоненты переиспользуемыми.
