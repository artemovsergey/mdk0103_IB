# Практическая работа 9. Создание списка с прокруткой

В этой работе вы научитесь создавать прокручиваемый список в приложении React Native.

Вы будете работать с приложением **Affirmations** («Аффирмации»), которое отображает список позитивных утверждений с красивыми изображениями.

### Необходимые условия

- Знание массивов в TypeScript.
- Умение создавать макеты с помощью `View`, `Text` и `Image`.
- Опыт запуска приложения Expo.

### Что вы узнаете

- Как создать элемент списка (карточку).
- Как создать прокручиваемый список с помощью `FlatList`.

### Что вы создадите

- Приложение, отображающее прокручиваемый список аффирмаций.

## Подготовка проекта

1. Создайте проект Expo с шаблоном TypeScript:

```bash
npx create-expo-app@latest affirmations --template blank-typescript
cd affirmations
npm install
```

2. Поместите в папку `assets` изображения для аффирмаций (например, `image1.png`, `image2.png`, ...).

## Шаг 1. Модель данных

Каждая аффирмация состоит из текста и изображения. Опишем её тип:

```tsx
import type { ImageSourcePropType } from 'react-native';

type Affirmation = {
  text: string
  image: ImageSourcePropType
}
```

## Шаг 2. Данные

Создадим массив аффирмаций:

```tsx
const affirmations: Affirmation[] = [
  { text: "Я полон энергии и энтузиазма", image: require('./assets/image1.png') },
  { text: "Каждый день я становлюсь лучше", image: require('./assets/image2.png') },
  { text: "Я верю в свои силы", image: require('./assets/image3.png') },
  { text: "У меня всё получается", image: require('./assets/image4.png') },
  { text: "Я открыт новым возможностям", image: require('./assets/image5.png') },
  { text: "Я благодарен за каждый день", image: require('./assets/image6.png') },
]
```

## Шаг 3. Карточка аффирмации

Каждый элемент списка — карточка: изображение сверху и текст под ним. Создадим компонент `AffirmationCard`:

```tsx
import { Image, StyleSheet, Text, View } from 'react-native';

function AffirmationCard({ affirmation }: { affirmation: Affirmation }) {
  return (
    <View style={styles.card}>
      <Image source={affirmation.image} style={styles.image} />
      <Text style={styles.text}>{affirmation.text}</Text>
    </View>
  )
}
```

Стили карточки:

```tsx
card: {
  backgroundColor: '#FFFFFF',
  borderRadius: 12,
  overflow: 'hidden',
  marginVertical: 8,
},
image: {
  width: '100%',
  height: 194,
  resizeMode: 'cover',
},
text: {
  fontSize: 18,
  padding: 16,
},
```

> Свойство `overflow: 'hidden'` обрезает изображение по скруглённым углам карточки.

## Шаг 4. Прокручиваемый список FlatList

Для прокручиваемых списков в React Native используется компонент **`FlatList`**. Он отображает только видимые элементы и поэтому подходит для длинных списков.

Основные атрибуты `FlatList`:

| Атрибут | Назначение |
|:--------|:-----------|
| `data` | массив данных |
| `renderItem` | функция, возвращающая элемент для каждого пункта |
| `keyExtractor` | функция, возвращающая уникальный ключ элемента |

```tsx
import { FlatList } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <FlatList
        data={affirmations}
        renderItem={({ item }) => <AffirmationCard affirmation={item} />}
        keyExtractor={(item, index) => index.toString()}
      />
      <StatusBar style="auto" />
    </View>
  )
}
```

- `data` — наш массив аффирмаций.
- `renderItem` — получает объект `{ item }`, где `item` — очередная аффирмация.
- `keyExtractor` — возвращает уникальный ключ для каждого элемента (необходим для оптимизации).

## Полный код приложения

```tsx
import { StatusBar } from 'expo-status-bar';
import { FlatList, Image, StyleSheet, Text, View } from 'react-native';
import type { ImageSourcePropType } from 'react-native';

type Affirmation = {
  text: string
  image: ImageSourcePropType
}

const affirmations: Affirmation[] = [
  { text: "Я полон энергии и энтузиазма", image: require('./assets/image1.png') },
  { text: "Каждый день я становлюсь лучше", image: require('./assets/image2.png') },
  { text: "Я верю в свои силы", image: require('./assets/image3.png') },
  { text: "У меня всё получается", image: require('./assets/image4.png') },
  { text: "Я открыт новым возможностям", image: require('./assets/image5.png') },
  { text: "Я благодарен за каждый день", image: require('./assets/image6.png') },
]

function AffirmationCard({ affirmation }: { affirmation: Affirmation }) {
  return (
    <View style={styles.card}>
      <Image source={affirmation.image} style={styles.image} />
      <Text style={styles.text}>{affirmation.text}</Text>
    </View>
  )
}

export default function App() {
  return (
    <View style={styles.container}>
      <FlatList
        data={affirmations}
        renderItem={({ item }) => <AffirmationCard affirmation={item} />}
        keyExtractor={(item, index) => index.toString()}
        contentContainerStyle={styles.list}
      />
      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#EDE7F6',
  },
  list: {
    padding: 16,
  },
  card: {
    backgroundColor: '#FFFFFF',
    borderRadius: 12,
    overflow: 'hidden',
    marginVertical: 8,
  },
  image: {
    width: '100%',
    height: 194,
    resizeMode: 'cover',
  },
  text: {
    fontSize: 18,
    padding: 16,
  },
})
```

## Проверка работы

1. Запустите приложение.
2. Прокрутите список — все аффирмации отображаются карточками.
3. Измените изображения или добавьте новые аффирмации в массив — список обновится.

## Задания для самостоятельной работы

1. Добавьте в массив ещё 4 аффирмации.
2. Сделайте текст аффирмации полужирным.
3. Добавьте под текстом подпись автора аффирмации.

## Резюме

- Модель данных описывается типом TypeScript.
- Карточка — это компонент, объединяющий изображение и текст.
- `FlatList` создаёт прокручиваемый список из массива данных.
- `renderItem` возвращает компонент для каждого элемента списка.
