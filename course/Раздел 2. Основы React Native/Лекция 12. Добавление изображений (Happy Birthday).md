# Лекция 12. Добавление изображений в приложение

В приложении «С днём рождения» пока есть только текст. Добавим в него праздничное изображение. В этой лекции вы научитесь подключать изображения и управлять их отображением с помощью компонента `Image`.

### Необходимые условия

- Умение создавать и запускать приложение Expo.
- Знание компонентов `Text`, `View` и `StyleSheet`.

### Что вы узнаете

- Как добавить изображение в проект (папка `assets`).
- Как отобразить изображение с помощью компонента `Image`.
- Как управлять размером и масштабированием изображения.

### Что вы создадите

- Усовершенствуете приложение «С днём рождения», добавив в него изображение.

## Где хранятся изображения

В Expo все изображения и прочие файлы приложения хранятся в папке **`assets`**. Поместите туда файл с изображением (например, `party.png`).

```
happy-birthday/
├── assets/
│   ├── icon.png
│   ├── splash-icon.png
│   └── party.png      ← наше изображение
├── App.tsx
└── ...
```

## Подключение изображения

Чтобы использовать изображение из папки `assets`, его подключают функцией `require` с путём к файлу:

```tsx
const partyImage = require('./assets/party.png')
```

Путь задаётся **относительно файла**, в котором находится код. Результат `require` передают компоненту `Image` в атрибут `source`.

## Компонент Image

Компонент `Image` отображает изображение:

```tsx
import { Image, StyleSheet, Text, View } from 'react-native';

const partyImage = require('./assets/party.png');

export default function App() {
  return (
    <View style={styles.container}>
      <Image source={partyImage} />
      <Text style={styles.title}>С днём рождения, Александр!</Text>
    </View>
  );
}
```

Обязательный атрибут — `source`, источник изображения. Также рекомендуется всегда задавать `accessibilityLabel` — текстовое описание изображения для программ чтения с экрана:

```tsx
<Image source={partyImage} accessibilityLabel="Праздничная открытка" />
```

## Размер изображения

Без явного размера изображение отображается в своих «натуральных» размерах, что обычно не подходит. Размер задаётся в стиле:

```tsx
const styles = StyleSheet.create({
  image: {
    width: 300,
    height: 200,
  },
})
```

```tsx
<Image source={partyImage} style={styles.image} />
```

Чтобы изображение заняло всю ширину экрана, используют `width: '100%'`:

```tsx
image: {
  width: '100%',
  height: 200,
},
```

## Масштабирование: resizeMode

Если заданные размеры не совпадают с пропорциями изображения, оно может исказиться. Свойство `resizeMode` управляет тем, как изображение подгоняется под размер:

```tsx
<Image
  source={partyImage}
  style={styles.image}
  resizeMode="cover"
/>
```

| Значение | Поведение |
|:---------|:----------|
| `cover` | заполняет область, сохраняя пропорции; края могут обрезаться |
| `contain` | полностью помещается в область, сохраняя пропорции |
| `stretch` | растягивается под размер (искажает пропорции) |
| `center` | центрируется без масштабирования |

## Изображение как фон

Часто изображение нужно растянуть на весь экран и разместить поверх него текст. Для этого используют компонент `ImageBackground`:

```tsx
import { ImageBackground, StyleSheet, Text } from 'react-native';

export default function App() {
  return (
    <ImageBackground
      source={require('./assets/party.png')}
      style={styles.container}
    >
      <Text style={styles.title}>С днём рождения!</Text>
    </ImageBackground>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#FFFFFF',
  },
});
```

`ImageBackground` — это тот же `Image`, но внутрь него можно помещать другие компоненты.

## Приложение целиком

Файл `App.tsx`:

```tsx
import { StatusBar } from 'expo-status-bar';
import { Image, StyleSheet, Text, View } from 'react-native';

const partyImage = require('./assets/party.png');

export default function App() {
  return (
    <View style={styles.container}>
      <Image
        source={partyImage}
        style={styles.image}
        accessibilityLabel="Праздничная открытка"
      />
      <Text style={styles.title}>С днём рождения, Александр!</Text>
      <Text style={styles.subtitle}>От Ирины</Text>
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#FFE6F0',
    alignItems: 'center',
    justifyContent: 'center',
    padding: 16,
  },
  image: {
    width: '100%',
    height: 200,
    borderRadius: 16,
    marginBottom: 16,
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#4A3F92',
    textAlign: 'center',
    marginBottom: 8,
  },
  subtitle: {
    fontSize: 16,
    color: '#555555',
  },
});
```

## Резюме

- Изображения хранятся в папке `assets`.
- Изображение подключается функцией `require` и отображается компонентом `Image`.
- `source` — источник изображения, `accessibilityLabel` — описание для программ чтения с экрана.
- Размер задаётся в стиле (`width`, `height`).
- `resizeMode` управляет масштабированием.
- `ImageBackground` позволяет размещать компоненты поверх изображения.
