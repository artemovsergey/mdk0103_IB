# Практическая работа 10. Установка значка приложения

Значок приложения — важная часть его оформления. Он отображается на главном экране телефона, в списке приложений и в настройках. В этой работе вы научитесь менять значок приложения в проекте Expo.

### Что вы узнаете

- Где хранится значок приложения в проекте Expo.
- Как заменить значок в файле конфигурации `app.json`.
- Что такое адаптивная иконка Android.

### Что вы сделаете

- Замените стандартный значок приложения **Affirmations** на собственный.

## Где хранится значок

В проекте Expo вся конфигурация приложения описана в файле **`app.json`** в корне проекта. Откроем его:

```json
{
  "expo": {
    "name": "affirmations",
    "slug": "affirmations",
    "version": "1.0.0",
    "orientation": "portrait",
    "icon": "./assets/icon.png",
    "userInterfaceStyle": "light",
    "android": {
      "adaptiveIcon": {
        "backgroundColor": "#FFFFFF",
        "foregroundImage": "./assets/android-icon-foreground.png"
      }
    },
    "web": {
      "favicon": "./assets/favicon.png"
    }
  }
}
```

За значок отвечают следующие поля:

| Поле | Назначение |
|:-----|:-----------|
| `icon` | основной значок приложения (файл `assets/icon.png`) |
| `android.adaptiveIcon.foregroundImage` | передний слой адаптивной иконки Android |
| `android.adaptiveIcon.backgroundColor` | фоновый цвет адаптивной иконки |
| `web.favicon` | значок для веб-версии |

## Изображение значка

Значок — это квадратное изображение. Обычно его готовят размером **1024×1024** пикселей в формате PNG. Исходник значка хранится в папке `assets`.

Подготовьте собственное изображение значка (например, с тематикой аффирмаций — солнце или сердце) и сохраните его как `assets/icon.png`, заменив стандартный файл.

> В отличие от Android Studio, где для разных плотностей экрана готовят несколько размеров (mdpi, hdpi и т. д.), Expo сам генерирует все нужные размеры из одного исходного изображения при сборке приложения.

## Адаптивная иконка Android

На Android начиная с версии 8.0 значок приложения может быть **адаптивным** — состоять из двух слоёв:

- **передний план** (foreground) — основное изображение;
- **фон** (background) — цвет или узор под ним.

Производители устройств накладывают на эти слои маску (круг, скруглённый квадрат и т. д.), чтобы все значки на устройстве имели единую форму. Поэтому важные детали изображения должны находиться в **безопасной зоне** — центральной части иконки.

В `app.json` адаптивная иконка описывается так:

```json
"android": {
  "adaptiveIcon": {
    "backgroundColor": "#FFFFFF",
    "foregroundImage": "./assets/android-icon-foreground.png",
    "monochromeImage": "./assets/android-icon-monochrome.png"
  }
}
```

- `foregroundImage` — изображение переднего плана.
- `backgroundColor` — цвет фона.
- `monochromeImage` — одноцветная версия значка (используется для «тематических» иконок).

## Изменение значка

Чтобы изменить значок приложения:

1. Подготовьте изображение 1024×1024 PNG.
2. Замените файл `assets/icon.png`.
3. При необходимости замените `assets/android-icon-foreground.png` и задайте `backgroundColor` в `app.json`.
4. Проверьте результат.

В веб-режиме (`npx expo start --web`) обновление значка можно увидеть в заголовке вкладки браузера. На телефоне значок обновится после сборки приложения (`npx expo run:android` или при установке через Expo Go обновлённой версии).

## Название приложения

Пока вы в `app.json`, заодно задайте понятное название приложения:

```json
"name": "Affirmations",
```

Значение `name` отображается под значком на главном экране. Значение `slug` (слаг) используется технически и должно быть в нижнем регистре без пробелов.

## Проверка работы

1. Замените `assets/icon.png` на собственное изображение.
2. Измените `name` в `app.json`.
3. Перезапустите приложение и проверьте, что значок и название изменились.

## Резюме

- Значок приложения хранится в папке `assets` и настраивается в файле `app.json`.
- Expo сам генерирует значки всех размеров из одного исходного изображения.
- Адаптивная иконка Android состоит из переднего плана и фона.
- Название приложения задаётся полем `name`.
