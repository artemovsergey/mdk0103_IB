# Практическая работа 7. Создание интерактивного приложения Dice Roller

В этой работе вы создадите интерактивное приложение **Dice Roller** («Бросок костей»), которое позволит пользователю нажимать на кнопку, чтобы бросить кости. Результат броска отображается на экране в виде изображения.

Приложение разрабатывается на языке **TypeScript** с использованием фреймворка **React Native** и инструмента **Expo**. Сначала вы создадите макет приложения, а затем напишете логику обработки нажатия на кнопку.

### Необходимые условия

- Настроенное окружение для разработки на React Native (см. файл «Настройка окружения Expo»).
- Умение создать и запустить базовое приложение Expo.
- Знание основ TypeScript: переменные, функции, типы данных.

### Что вы узнаете

- Как добавить кнопку в приложение React Native.
- Как добавить кнопку обработку нажатия.
- Как отображать изображения из папки `assets`.
- Как хранить и обновлять данные с помощью хука `useState`.
- Как разбивать интерфейс на React-компоненты.

### Что вы создадите

- Интерактивное приложение **Dice Roller**, которое позволяет пользователю бросать кости и показывает результат броска.

После завершения на экране по центру будет изображение игральной кости и кнопка «Бросить кости». При нажатии на кнопку изображение меняется на случайную грань.

## Подготовка проекта

- Скачайте стартовый проект `dice-roller-starter.zip` из папки `repositories`.

- Откройте файл `App.tsx` в редакторе - именно в нём мы будем работать.

## Обзор стартового кода

Стартовый проект содержит заготовку экрана и изображения шести граней кости в папке `assets/dice`.

Файл `App.tsx` выглядит так:

```tsx
import { StatusBar } from 'expo-status-bar';
import { StyleSheet, View } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <StatusBar style="auto" />
      {/* TODO: добавить изображение кубика и кнопку броска */}
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#FEEDDD',
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

Разберём код:

- `View` - это базовый контейнер в React Native, аналог `<div>` в веб-разметке.
- `Text` - компонент для отображения текста (в React Native нельзя выводить текст без него).
- `StyleSheet.create` - способ описать стили приложения отдельно от разметки.
- Стиль `container` задаёт: контейнер занимает весь экран (`flex: 1`), фон, а `alignItems: 'center'` и `justifyContent: 'center'` центрируют содержимое по горизонтали и вертикали.

## Создание вертикального макета

Наше приложение состоит из двух элементов: изображение кости и кнопка. Расположим их друг под другом. Для этого создадим отдельный компонент `DiceWithButtonAndImage`.

В React Native компонент - это функция, которая возвращает разметку (`JSX`). Именуем компоненты с заглавной буквы.

Добавьте в `App.tsx` новый компонент и вызовите его из `App`:

```tsx
function DiceWithButtonAndImage() {
  return (
    <View style={styles.diceContainer}>
      {/* Здесь будут изображение и кнопка */}
    </View>
  );
}

export default function App() {
  return (
    <View style={styles.container}>
      <StatusBar style="auto" />
      <DiceWithButtonAndImage />
    </View>
  );
}
```

И добавьте стиль `diceContainer`:

```tsx
const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#FEEDDD',
    alignItems: 'center',
    justifyContent: 'center',
  },
  diceContainer: {
    alignItems: 'center',
  },
});
```

> Обратите внимание: в JSX логика разметки заключена в круглые скобки после `return`, а компоненты записываются как `<ИмяКомпонента />`.

## Добавление изображения

В папке `assets/dice` уже лежат шесть изображений: `dice_1.png` ... `dice_6.png`.

Чтобы отобразить изображение, используется компонент `Image`. Источник изображения задаётся с помощью функции `require`, которая принимает путь к файлу относительно текущего файла.

Сначала опишем все шесть изображений в виде объекта, где ключ - число на грани, а значение - источник изображения:

```tsx
import type { ImageSourcePropType } from 'react-native';

const DICE_IMAGES: Record<number, ImageSourcePropType> = {
  1: require('./assets/dice/dice_1.png'),
  2: require('./assets/dice/dice_2.png'),
  3: require('./assets/dice/dice_3.png'),
  4: require('./assets/dice/dice_4.png'),
  5: require('./assets/dice/dice_5.png'),
  6: require('./assets/dice/dice_6.png'),
};
```

Теперь добавим изображение в компонент:

```tsx
function DiceWithButtonAndImage() {
  return (
    <View style={styles.diceContainer}>
      <Image
        source={DICE_IMAGES[1]}
        style={styles.diceImage}
        accessibilityLabel="Результат броска: 1"
      />
    </View>
  );
}
```

> `accessibilityLabel` - это текстовое описание изображения для людей, использующих программы чтения с экрана. Его нужно указывать для всех значимых изображений.

Не забудьте импортировать `Image` в начале файла:

```tsx
import { Image, StyleSheet, View } from 'react-native';
```

И добавьте стиль для изображения:

```tsx
diceImage: {
  width: 140,
  height: 140,
  marginBottom: 32,
},
```

## Добавление кнопки

В React Native для кнопки можно использовать компонент `Pressable`. Он реагирует на нажатие и позволяет оформить кнопку как угодно.

Добавьте кнопку под изображением:

```tsx
import { Image, Pressable, StyleSheet, Text, View } from 'react-native';

function DiceWithButtonAndImage() {
  return (
    <View style={styles.diceContainer}>
      <Image
        source={DICE_IMAGES[1]}
        style={styles.diceImage}
        accessibilityLabel="Результат броска: 1"
      />
      <Pressable style={styles.button} onPress={() => {}}>
        <Text style={styles.buttonText}>Бросить кости</Text>
      </Pressable>
    </View>
  );
}
```

Обратите внимание:

- Параметр `onPress` - это функция (обратный вызов), которая выполнится при нажатии. Пока она пустая.
- Внутри `Pressable` находится компонент `Text` с подписью кнопки.
- Стиль кнопки передаётся в параметр `style`.

Добавьте стили кнопки:

```tsx
button: {
  backgroundColor: '#4A3F92',
  paddingHorizontal: 24,
  paddingVertical: 14,
  borderRadius: 12,
},
buttonText: {
  color: '#FFFFFF',
  fontSize: 18,
  fontWeight: '600',
},
```

## Создание логики броска

Теперь сделаем кнопку интерактивной. Результат броска - это число от 1 до 6, которое должно «запоминаться» между перерисовками экрана. Для этого в React есть хук `useState`.

Сначала напишем функцию, возвращающую случайное число от 1 до 6:

```tsx
function rollDice(): number {
  return Math.floor(Math.random() * 6) + 1;
}
```

> `Math.random()` возвращает случайное число от 0 (включительно) до 1 (не включительно). Умножив на 6 и округлив вниз с помощью `Math.floor`, получаем число от 0 до 5, а прибавив 1 - от 1 до 6.

Теперь добавим состояние в компонент:

```tsx
import { useState } from 'react';

function DiceWithButtonAndImage() {
  const [result, setResult] = useState(1);
  ...
}
```

- `result` - текущее значение (какой гранью повёрнута кость).
- `setResult` - функция, которая обновляет значение.
- `useState(1)` - начальное значение равно 1.

При изменении `result` React автоматически обновит интерфейс - это называется **перерисовкой** (ререндером).

Осталось связать всё вместе: при нажатии на кнопку записывать в состояние случайное число, а источник изображения брать из состояния.

```tsx
function DiceWithButtonAndImage() {
  const [result, setResult] = useState(1);

  return (
    <View style={styles.diceContainer}>
      <Image
        source={DICE_IMAGES[result]}
        style={styles.diceImage}
        accessibilityLabel={`Результат броска: ${result}`}
      />
      <Pressable style={styles.button} onPress={() => setResult(rollDice())}>
        <Text style={styles.buttonText}>Бросить кости</Text>
      </Pressable>
    </View>
  );
}
```

Теперь при каждом нажатии кнопки выполняется `setResult(rollDice())`: генерируется случайное число, записывается в состояние, и изображение меняется.

## Полный код приложения

Файл `App.tsx` целиком:

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import { Image, Pressable, StyleSheet, Text, View } from 'react-native';
import type { ImageSourcePropType } from 'react-native';

const DICE_IMAGES: Record<number, ImageSourcePropType> = {
  1: require('./assets/dice/dice_1.png'),
  2: require('./assets/dice/dice_2.png'),
  3: require('./assets/dice/dice_3.png'),
  4: require('./assets/dice/dice_4.png'),
  5: require('./assets/dice/dice_5.png'),
  6: require('./assets/dice/dice_6.png'),
};

function rollDice(): number {
  return Math.floor(Math.random() * 6) + 1;
}

function DiceWithButtonAndImage() {
  const [result, setResult] = useState(1);

  return (
    <View style={styles.diceContainer}>
      <Image
        source={DICE_IMAGES[result]}
        style={styles.diceImage}
        accessibilityLabel={`Результат броска: ${result}`}
      />
      <Pressable style={styles.button} onPress={() => setResult(rollDice())}>
        <Text style={styles.buttonText}>Бросить кости</Text>
      </Pressable>
    </View>
  );
}

export default function App() {
  return (
    <View style={styles.container}>
      <StatusBar style="auto" />
      <DiceWithButtonAndImage />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#FEEDDD',
    alignItems: 'center',
    justifyContent: 'center',
  },
  diceContainer: {
    alignItems: 'center',
  },
  diceImage: {
    width: 140,
    height: 140,
    marginBottom: 32,
  },
  button: {
    backgroundColor: '#4A3F92',
    paddingHorizontal: 24,
    paddingVertical: 14,
    borderRadius: 12,
  },
  buttonText: {
    color: '#FFFFFF',
    fontSize: 18,
    fontWeight: '600',
  },
});
```

## Резюме

- Компонент в React Native - это функция, возвращающая разметку JSX.
- Макет строится из контейнеров `View`, а текст выводится через `Text`.
- Стили описываются в `StyleSheet.create` и передаются в параметр `style`.
- Изображения из папки `assets` подключаются через `require` и показываются компонентом `Image`.
- Кнопка реализуется компонентом `Pressable` с обработчиком `onPress`.
- Хук `useState` хранит данные, которые меняются во время работы приложения, и автоматически обновляет интерфейс при их изменении.
