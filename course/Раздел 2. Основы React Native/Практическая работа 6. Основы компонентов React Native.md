# Практическая работа 6. Основы компонентов React Native

Этот урок посвящён созданию макетов с использованием изученных компонентов React Native: `View`, `Text`, `Image` и `StyleSheet`. Упражнения основаны на реальных примерах оформления экранов.

В упражнениях вам даются спецификации интерфейса: размеры шрифтов, отступы, цвета. Эти спецификации помогают создавать единообразные интерфейсы. Умение следовать спецификациям и разбираться в документации — важный навык разработчика.

Выполните три упражнения. Каждое — отдельное приложение (или отдельный экран) в проекте Expo.

## Упражнение 1. Приложение «Статья»

Создайте экран, на котором отображается статья об учебнике по React Native.

### Спецификация интерфейса

- Изображение заполняет всю ширину экрана.
- Первый текст: размер шрифта `24`, отступы `16` со всех сторон.
- Второй текст: размер шрифта по умолчанию (`14`), отступы `16` по бокам, выравнивание по ширине.
- Третий текст: размер шрифта по умолчанию, отступы `16` со всех сторон, выравнивание по ширине.

### Текст

```
Учебник по React Native
React Native — это фреймворк для создания нативных мобильных приложений с помощью TypeScript. Он позволяет писать код один раз и запускать его на Android и iOS, используя нативные компоненты.
В этом уроке вы создадите простой интерфейс с помощью декларативных компонентов. Вы описываете, какие элементы нужны, а React Native сам отрисовывает их на экране.
```

### Подсказка

Для изображения используйте файл `bg_article_background.png` из папки `assets`. Для выравнивания текста по ширине задайте `textAlign: 'justify'`.

## Упражнение 2. Приложение «Диспетчер задач»

Создайте экран, который пользователь увидит, когда выполнит все задачи за день.

### Спецификация интерфейса

- Выровняйте всё содержимое по центру экрана по вертикали и горизонтали.
- Первый текст: жирный шрифт (`fontWeight: 'bold'`), отступ сверху `24`, снизу `8`.
- Второй текст: размер шрифта `16`.

### Ресурсы

Изображение `ic_task_completed.png` из папки `assets`. Текст:

```
Все задания выполнены
Отличная работа!
```

## Упражнение 3. Приложение «Квадрант»

Создайте приложение, которое отображает информацию о компонентах React Native. Экран разделён на четыре квадранта; в каждом — название компонента и его описание в одном предложении.

### Спецификация интерфейса

- Разделите экран на четыре равные части (два ряда по два квадранта).
- Для каждого квадранта: отступы `16` со всех сторон, содержимое по центру (по вертикали и горизонтали).
- Первый текст (название): полужирный шрифт, отступ снизу `16`.
- Второй текст (описание): размер шрифта по умолчанию.

### Цвета

- `#EADDFF`
- `#D0BCFF`
- `#B69DF8`
- `#F6EDFF`

### Содержимое квадрантов

```
Компонент Text
Отображает текст и поддерживает базовые стили шрифта.

Компонент Image
Отображает изображение из файла или из сети.

Компонент Row (ряд)
Аналог строки: компоненты View с flexDirection 'row' располагают элементы по горизонтали.

Компонент Column (колонка)
Компоненты View с flexDirection 'column' располагают элементы по вертикали.
```

### Подсказка по раскладке квадрантов

Чтобы разместить два квадранта в ряд, используйте внешний `View` с `flex: 1` и внутренние `View` с `flexDirection: 'row'` и `flex: 1`:

```tsx
<View style={styles.row}>
  <View style={[styles.quadrant, { backgroundColor: '#EADDFF' }]}>
    <Text style={styles.title}>Компонент Text</Text>
    <Text>Отображает текст...</Text>
  </View>
  <View style={[styles.quadrant, { backgroundColor: '#D0BCFF' }]}>
    ...
  </View>
</View>
```

## Резюме

- `View` группирует компоненты и задаёт раскладку.
- `Text` отображает текст, `Image` — изображения.
- Отступы (`padding`, `margin`), размеры шрифта (`fontSize`) и выравнивание (`textAlign`) задаются в стилях.
- Для раскладки в ряд и колонку используется flexbox.
