# Лекция 7. Введение в React Native

В этом уроке вы создадите простое мобильное приложение «С днём рождения», которое выводит на экран поздравительное сообщение. Приложение создаётся на языке TypeScript с использованием фреймворка **React Native** и инструмента **Expo**.

### Что вы узнаете

- Что такое пользовательский интерфейс и компоненты.
- Как устроено приложение React Native.
- Как отображать текст с помощью компонента `Text`.
- Как располагать элементы с помощью компонента `View`.
- Как оформлять элементы с помощью `StyleSheet`.

### Что вы создадите

Приложение, отображающее поздравление с днём рождения, которое выглядит примерно так:

```
┌─────────────────────┐
│                     │
│   С днём рождения,  │
│      Александр!     │
│                     │
│      От Ирины       │
│                     │
└─────────────────────┘
```

## Что такое пользовательский интерфейс

**Пользовательский интерфейс (UI)** — это всё, что вы видите на экране: текст, изображения, кнопки, поля ввода, а также то, как они расположены. Каждый элемент экрана называется **компонентом**.

В приложении «Настройки» можно найти множество компонентов: заголовки, переключатели, списки. Почти всё, что вы видите, — это компонент. Одни компоненты интерактивны (кнопки, поля ввода), другие декоративны (изображения).

## Что такое React Native

**React Native** — это фреймворк для создания мобильных приложений на языке TypeScript (JavaScript). Вместо того чтобы описывать интерфейс императивно (шаг за шагом), вы **описываете, как интерфейс должен выглядеть**, а React Native сам его отрисовывает. Такой подход называется **декларативным**.

Приложение React Native состоит из **компонентов** — функций, которые возвращают разметку JSX:

```tsx
function Greeting() {
  return <Text>Привет!</Text>
}
```

В React Native используются настоящие нативные компоненты: `Text`, `View`, `Image`, `Pressable` и другие. Код пишется один раз, а работает на Android и iOS.

> **Expo** — это инструмент поверх React Native, который упрощает создание и запуск приложений (без настройки Android SDK). Запуск приложения описан в файле «Настройка окружения Expo».

## Создание проекта

Создайте новый проект с шаблоном TypeScript (подробнее — в файле «Настройка окружения Expo»):

```bash
npx create-expo-app@latest happy-birthday --template blank-typescript
cd happy-birthday
npm install
```

Запустите приложение:

```bash
npx expo start
```

Нажмите `w` для запуска в браузере, `a` — на эмуляторе Android, или отсканируйте QR-код приложением Expo Go.

## Структура приложения

Откройте файл `App.tsx` — это главный компонент приложения:

```tsx
import { StatusBar } from 'expo-status-bar';
import { StyleSheet, Text, View } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text>Open up App.tsx to start working on your app!</Text>
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

Разберём по частям:

- `import ... from 'react-native'` — подключает встроенные компоненты React Native.
- `export default function App()` — главный компонент приложения.
- `return (...)` — компонент возвращает разметку JSX.
- `<View>` — контейнер, аналог блока. Внутри него размещаются другие компоненты.
- `<Text>` — компонент для отображения текста. В React Native текст нельзя выводить без него.
- `StyleSheet.create({...})` — описание стилей.

## Компонент Text

Компонент `Text` выводит текст. Его содержимое можно задать прямо в разметке:

```tsx
<Text>С днём рождения!</Text>
```

Текст также можно передать через переменную (подстановка JSX-выражения в фигурных скобках):

```tsx
const name = "Александр"

<Text>С днём рождения, {name}!</Text>
```

## Форматирование текста

Стиль передаётся компоненту через атрибут `style`:

```tsx
<Text style={styles.title}>С днём рождения, Александр!</Text>
```

А сами стили описываются в `StyleSheet.create`:

```tsx
const styles = StyleSheet.create({
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#4A3F92',
    textAlign: 'center',
  },
})
```

Основные свойства текста:

| Свойство | Что задаёт | Пример |
|:---------|:-----------|:-------|
| `fontSize` | размер шрифта | `24` |
| `fontWeight` | жирность | `'bold'` |
| `color` | цвет текста | `'#4A3F92'` |
| `textAlign` | выравнивание | `'center'` |

> В React Native размеры задаются обычными числами (без единиц). Они автоматически подстраиваются под плотность экрана устройства.

## Компонент View и расположение

Компонент `View` — это контейнер, который группирует другие компоненты и задаёт им расположение. По умолчанию дочерние элементы выстраиваются **вертикально** (колонкой):

```tsx
<View style={styles.container}>
  <Text>С днём рождения, Александр!</Text>
  <Text>От Ирины</Text>
</View>
```

Два текста расположатся один под другим.

## Flexbox и центрирование

Для расположения элементов используется **flexbox** — система раскладки, общая для React Native и веб-разработки. Основные свойства:

| Свойство | Значение | Действие |
|:---------|:---------|:---------|
| `flex: 1` | число | элемент занимает всё доступное пространство |
| `flexDirection` | `'column'`, `'row'` | направление элементов (вертикально/горизонтально) |
| `justifyContent` | `'center'`, `'space-between'` | выравнивание по главной оси |
| `alignItems` | `'center'`, `'stretch'` | выравнивание по поперечной оси |

Чтобы отцентрировать содержимое по вертикали и горизонтали, используют комбинацию:

```tsx
container: {
  flex: 1,
  alignItems: 'center',
  justifyContent: 'center',
},
```

## Приложение целиком

Соберём поздравление. Файл `App.tsx`:

```tsx
import { StatusBar } from 'expo-status-bar';
import { StyleSheet, Text, View } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>С днём рождения, Александр!</Text>
      <Text style={styles.subtitle}>От Ирины</Text>
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#FFE6F0',
    alignItems: 'center',
    justifyContent: 'center',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#4A3F92',
    textAlign: 'center',
    marginBottom: 8,
  },
  subtitle: {
    fontSize: 16,
    color: '#555555',
  },
});
```

Сохраните файл — приложение обновится автоматически.

## Резюме

- Пользовательский интерфейс состоит из компонентов.
- React Native — декларативный фреймворк: вы описываете, как интерфейс должен выглядеть.
- `Text` отображает текст, `View` — контейнер для других элементов.
- Стили описываются в `StyleSheet.create` и передаются через атрибут `style`.
- Расположение задаётся с помощью flexbox (`justifyContent`, `alignItems`, `flexDirection`).
