# Лекция 14. Жизненный цикл приложения

Когда вы запускаете приложение, сворачиваете его или закрываете, оно проходит через разные состояния. Понимание этого «жизненного цикла» помогает правильно загружать данные, сохранять состояние и освобождать ресурсы.

В React Native есть два уровня жизненного цикла: **жизненный цикл компонента** и **состояние приложения** (`AppState`).

На этом занятии вы научитесь выполнять код в нужные моменты жизненного цикла и понимать, когда состояние приложения сохраняется.

### Что вы узнаете

- Как работает жизненный цикл компонента React.
- Как выполнять код при появлении и удалении компонента (`useEffect`).
- Как отслеживать состояние приложения (`AppState`).
- Почему в React Native состояние не сбрасывается при повороте экрана.

### Что вы будете создавать

Приложение **Dessert Clicker**: при каждом нажатии на десерт «покупается» одна порция, а на экране обновляется количество проданных десертов и общая выручка.

## Жизненный цикл компонента

У каждого компонента React есть три фазы жизненного цикла:

1. **Монтирование (mount)** — компонент создан и добавлен на экран.
2. **Обновление (update)** — компонент перерисован из-за изменения состояния или свойств.
3. **Размонтирование (unmount)** — компонент удалён с экрана.

Для выполнения кода в эти моменты используется хук **`useEffect`**.

## Хук useEffect

Хук `useEffect` выполняет код после отрисовки компонента. Первый аргумент — функция (эффект), второй — массив зависимостей.

```tsx
import { useEffect } from 'react';

function App() {
  useEffect(() => {
    console.log("Компонент смонтирован")

    // Функция возвращает "очистку" — выполнится при размонтировании
    return () => {
      console.log("Компонент размонтирован")
    }
  }, [])   // пустой массив = выполнить один раз при монтировании

  return <Text>Приложение</Text>
}
```

- Пустой массив `[]` — эффект выполняется **один раз** после монтирования.
- Если массив зависимостей содержит переменные, эффект выполняется при их изменении.
- Функция, возвращённая из эффекта, выполняется перед размонтированием (очистка ресурсов).

Пример: сохранение данных при размонтировании, подписка на события, таймеры.

## Состояние приложения: AppState

`AppState` сообщает, в каком состоянии находится всё приложение: активно оно, свёрнуто или неактивно.

```tsx
import { useEffect } from 'react';
import { AppState } from 'react-native';

function App() {
  useEffect(() => {
    const subscription = AppState.addEventListener('change', (state) => {
      console.log("Состояние приложения:", state)
    })

    return () => subscription.remove()
  }, [])

  return <Text>Приложение</Text>
}
```

Значения `AppState`:

| Состояние | Значение |
|:----------|:---------|
| `active` | приложение на переднем плане, пользователь работает с ним |
| `background` | приложение свёрнуто, но ещё запущено |
| `inactive` | переходное состояние (например, входящий звонок) |

Следите за переходом в `background` и обратно в `active`, чтобы, например, сохранить данные при сворачивании и обновить их при возврате.

## Почему состояние не сбрасывается при повороте экрана

В React Native состояние, хранящееся через `useState`, живёт в компоненте и **не сбрасывается** при повороте экрана или изменении размеров окна.

Это важное отличие, которое упрощает разработку:

```tsx
const [revenue, setRevenue] = useState(0)
// при повороте экрана revenue сохранит своё значение
```

Состояние теряется только при полном закрытии и повторном запуске приложения.

## Приложение Dessert Clicker

Соберём приложение: при нажатии на десерт увеличивается количество проданных порций и выручка.

```tsx
import { StatusBar } from 'expo-status-bar';
import { useEffect, useState } from 'react';
import { Pressable, StyleSheet, Text, View } from 'react-native';

const PRICE = 5   // цена одного десерта

export default function App() {
  const [count, setCount] = useState(0)
  const [revenue, setRevenue] = useState(0)

  useEffect(() => {
    console.log("Приложение запущено")
    return () => console.log("Приложение закрыто")
  }, [])

  function sellDessert() {
    setCount(count + 1)
    setRevenue(revenue + PRICE)
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Dessert Clicker</Text>
      <Pressable style={styles.button} onPress={sellDessert}>
        <Text style={styles.buttonText}>Купить десерт 🍰</Text>
      </Pressable>
      <Text style={styles.stats}>Продано: {count}</Text>
      <Text style={styles.stats}>Выручка: {revenue} ₽</Text>
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#FFF4E6',
    alignItems: 'center',
    justifyContent: 'center',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    marginBottom: 24,
  },
  button: {
    backgroundColor: '#D2691E',
    paddingHorizontal: 24,
    paddingVertical: 14,
    borderRadius: 12,
    marginBottom: 24,
  },
  buttonText: {
    color: '#FFFFFF',
    fontSize: 18,
  },
  stats: {
    fontSize: 16,
    marginVertical: 4,
  },
});
```

Запустите приложение, нажмите на кнопку несколько раз — количество и выручка будут расти. Поверните экран (или измените размер окна браузера) — значения не сбросятся.

## Резюме

- Жизненный цикл компонента: монтирование, обновление, размонтирование.
- `useEffect` выполняет код после отрисовки; возвращённая функция — очистка.
- `AppState` сообщает, активно ли приложение (в фоне или на переднем плане).
- В React Native состояние в `useState` не сбрасывается при повороте экрана.
