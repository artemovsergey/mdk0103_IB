# Практическая работа 15. Разработка приложения Material Design — Список супергероев

В этой работе вы примените принципы Material Design, создав приложение `Superheroes` — прокручиваемый список супергероев с оформленной темой.

### Предварительные условия

- Лекция 11 «Material Design».
- Умение работать с `FlatList` и состоянием.

### Что вы создадите

Приложение `Superheroes`, которое отображает список героев (имя, описание, изображение) с собственной цветовой палитрой, шрифтом и формами.

## Начало работы

Создайте проект Expo и установите библиотеки:

```
npx expo install react-native-paper expo-font @expo-google-fonts/cabin
```

## Шаг 2. Элемент списка

Каждый элемент показывает изображение, имя и описание:

```tsx
import { Card, Text } from 'react-native-paper'
import { Image, View } from 'react-native'

function HeroCard({ hero }: { hero: Hero }) {
  return (
    <Card style={styles.card}>
      <View style={styles.row}>
        <Image source={hero.image} style={styles.image} />
        <View style={styles.info}>
          <Text variant="titleLarge" style={styles.name}>{hero.name}</Text>
          <Text variant="bodyMedium">{hero.description}</Text>
        </View>
      </View>
    </Card>
  )
}
```

## Шаг 4. Типографика

Создайте файл `theme/Typography.ts` с настройкой шрифта Cabin:

```tsx
import { configureFonts, MD3LightTheme } from 'react-native-paper'

export const typography = configureFonts({
  config: {
    fontFamily: 'Cabin_400Regular',
    // при необходимости настройте отдельные стили:
    displayMedium: { fontFamily: 'Cabin_700Bold', fontSize: 20 },
  },
})
```

## Шаг 5. Формы

Скругления задаются через `theme.roundness`:

```tsx
const theme = {
  ...baseTheme,
  roundness: 8,
}
```

## Шаг 6. Тема

Соберём светлую и тёмную темы в `theme/Theme.ts`:

```tsx
import { MD3DarkTheme, MD3LightTheme } from 'react-native-paper'
import { colors } from './Colors'

export const lightTheme = {
  ...MD3LightTheme,
  roundness: 8,
  colors: { ...MD3LightTheme.colors, ...colors.light },
}

export const darkTheme = {
  ...MD3DarkTheme,
  roundness: 8,
  colors: { ...MD3DarkTheme.colors, ...colors.dark },
}
```

## Шаг 7. Главный экран


## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import { FlatList, Image, StyleSheet, View } from 'react-native';
import {
  Appbar,
  Card,
  MD3DarkTheme,
  MD3LightTheme,
  PaperProvider,
  Text,
} from 'react-native-paper';

type Hero = { id: string; name: string; description: string; image: any }

const heroes: Hero[] = [
  { id: '1', name: 'Nick the Night and Day', description: 'The Mobile Hero', image: require('./assets/hero1.png') },
  { id: '2', name: 'Reality Protector', description: 'Understands the absolute truth', image: require('./assets/hero2.png') },
  { id: '3', name: 'Andre the Giant', description: 'Mimics the light and night', image: require('./assets/hero3.png') },
]

const lightTheme = {
  ...MD3LightTheme,
  roundness: 8,
  colors: { ...MD3LightTheme.colors, primary: '#466800', background: '#FEFCF5' },
}
const darkTheme = {
  ...MD3DarkTheme,
  roundness: 8,
  colors: { ...MD3DarkTheme.colors, primary: '#ABD468', background: '#1B1C18' },
}

function HeroCard({ hero }: { hero: Hero }) {
  return (
    <Card style={styles.card}>
      <View style={styles.row}>
        <Image source={hero.image} style={styles.image} />
        <View style={styles.info}>
          <Text variant="titleLarge" style={styles.name}>{hero.name}</Text>
          <Text variant="bodyMedium">{hero.description}</Text>
        </View>
      </View>
    </Card>
  )
}

function SuperheroesApp() {
  const [isDark, setIsDark] = useState(false)
  return (
    <PaperProvider theme={isDark ? darkTheme : lightTheme}>
      <Appbar.Header>
        <Appbar.Content title="Superheroes" />
        <Appbar.Action
          icon={isDark ? 'weather-sunny' : 'weather-night'}
          onPress={() => setIsDark(!isDark)}
        />
      </Appbar.Header>
      <FlatList
        data={heroes}
        keyExtractor={(item) => item.id}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => <HeroCard hero={item} />}
      />
    </PaperProvider>
  )
}

export default function App() {
  return (
    <>
      <SuperheroesApp />
      <StatusBar style="auto" />
    </>
  );
}

const styles = StyleSheet.create({
  list: { padding: 16 },
  card: { marginBottom: 16 },
  row: { flexDirection: 'row', padding: 16, alignItems: 'center' },
  image: { width: 72, height: 72, borderRadius: 8, marginRight: 16 },
  info: { flex: 1 },
  name: { marginBottom: 4 },
})
```
