# Лекция 11. Применение темы Material Design

Material Design — это система дизайна, созданная Google для создания качественного и последовательного пользовательского интерфейса. Она содержит рекомендации по цветам, типографике, формам и компонентам.

В этом уроке вы примените Material Design в React Native с помощью библиотеки **React Native Paper** и создадите приложение **Woof** — список собак.

### Необходимые условия

- Умение создавать макеты (View, Text) и списки (FlatList).
- Базовое понимание компонентов и свойств.

### Что вы узнаете

- Как установить и настроить React Native Paper.
- Как применить цветовую палитру и светлую/тёмную тему.
- Как настроить типографику и шрифты.
- Как добавить верхнюю панель приложения (AppBar).

### Что вы создадите

Приложение **Woof**, которое отображает список собак и использует Material Design.

## Установка React Native Paper

React Native Paper — реализация Material Design 3 для React Native:

```
npx expo install react-native-paper
```

## Обзор приложения

Приложение показывает список собак с карточками. Есть верхняя панель с названием и переключателем темы.

## Тема: цвета и тема приложения

Paper поставляется с готовыми светлой и тёмной темами. Создадим собственную тему на их основе:

```tsx
import { MD3LightTheme, MD3DarkTheme } from 'react-native-paper'

const lightTheme = {
  ...MD3LightTheme,
  colors: {
    ...MD3LightTheme.colors,
    primary: '#7D5260',
    secondary: '#625B71',
    background: '#FFFBFE',
    surface: '#FFFBFE',
  },
}

const darkTheme = {
  ...MD3DarkTheme,
  colors: {
    ...MD3DarkTheme.colors,
    primary: '#D0BCFF',
    secondary: '#CCC2DC',
    background: '#1C1B1F',
    surface: '#1C1B1F',
  },
}
```

Провайдер темы делает её доступной всем компонентам:

```tsx
import { PaperProvider } from 'react-native-paper'

<PaperProvider theme={isDark ? darkTheme : lightTheme}>
  <App />
</PaperProvider>
```

## Типографика

В Paper есть стили текста: `displayLarge`, `headlineMedium`, `titleLarge`, `bodyMedium` и другие. Задать шрифт можно через `configureFonts`:

```tsx
import { configureFonts, MD3LightTheme } from 'react-native-paper'

const fontConfig = {
  config: {
    fontFamily: 'Cabin_400Regular',
  },
}

const theme = {
  ...MD3LightTheme,
  fonts: configureFonts({ config: { fontFamily: 'Cabin_400Regular' } }),
}
```

Чтобы подключить собственный шрифт, используйте `expo-font`:

```
npx expo install expo-font @expo-google-fonts/cabin
```

```tsx
import { useFonts, Cabin_400Regular, Cabin_700Bold } from '@expo-google-fonts/cabin'

const [fontsLoaded] = useFonts({ Cabin_400Regular, Cabin_700Bold })
if (!fontsLoaded) return null
```

## Верхняя панель приложения (AppBar)

`Appbar.Header` — это верхняя панель Material:

```tsx
import { Appbar } from 'react-native-paper'

<Appbar.Header>
  <Appbar.Content title="Woof" />
  <Appbar.Action icon={isDark ? 'weather-sunny' : 'weather-night'} onPress={toggleTheme} />
</Appbar.Header>
```

## Список собак

Используем компоненты Material: `Card`, `List`:

```tsx
import { Card, Text } from 'react-native-paper'

function DogCard({ dog }: { dog: Dog }) {
  return (
    <Card style={styles.card}>
      <Card.Title title={dog.name} subtitle={`${dog.age} лет`} />
      <Card.Content>
        <Text variant="bodyMedium">{dog.description}</Text>
      </Card.Content>
    </Card>
  )
}
```

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useState } from 'react';
import { FlatList, StyleSheet, useColorScheme } from 'react-native';
import {
  Appbar,
  Card,
  MD3DarkTheme,
  MD3LightTheme,
  PaperProvider,
  Text,
} from 'react-native-paper';

type Dog = { id: string; name: string; age: number; description: string }

const dogs: Dog[] = [
  { id: '1', name: 'Рекс', age: 3, description: 'Весёлый и активный пёс.' },
  { id: '2', name: 'Лесси', age: 5, description: 'Умная и спокойная собака.' },
  { id: '3', name: 'Барон', age: 2, description: 'Любит бегать и играть.' },
]

const lightTheme = { ...MD3LightTheme, colors: { ...MD3LightTheme.colors, primary: '#7D5260' } }
const darkTheme = { ...MD3DarkTheme, colors: { ...MD3DarkTheme.colors, primary: '#D0BCFF' } }

function WoofApp() {
  const systemScheme = useColorScheme()
  const [isDark, setIsDark] = useState(systemScheme === 'dark')
  const theme = isDark ? darkTheme : lightTheme

  return (
    <PaperProvider theme={theme}>
      <Appbar.Header>
        <Appbar.Content title="Woof" />
        <Appbar.Action
          icon={isDark ? 'weather-sunny' : 'weather-night'}
          onPress={() => setIsDark(!isDark)}
        />
      </Appbar.Header>

      <FlatList
        data={dogs}
        keyExtractor={(item) => item.id}
        contentContainerStyle={styles.list}
        renderItem={({ item }) => (
          <Card style={styles.card}>
            <Card.Title title={item.name} subtitle={`${item.age} лет`} />
            <Card.Content>
              <Text variant="bodyMedium">{item.description}</Text>
            </Card.Content>
          </Card>
        )}
      />
    </PaperProvider>
  )
}

export default function App() {
  return (
    <>
      <WoofApp />
      <StatusBar style="auto" />
    </>
  );
}

const styles = StyleSheet.create({
  list: { padding: 16, gap: 16 },
  card: { marginBottom: 16 },
})
```

## Резюме

- Material Design задаёт цвета, типографику, формы и компоненты.
- `PaperProvider` применяет тему ко всему приложению.
- `MD3LightTheme` / `MD3DarkTheme` — готовая светлая и тёмная темы.
- `Appbar` — верхняя панель, `Card` и `List` — готовые компоненты Material.
