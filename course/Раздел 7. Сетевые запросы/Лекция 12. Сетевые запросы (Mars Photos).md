# Лекция 12. Сетевые запросы

Большинство современных приложений подключаются к интернету, чтобы получать данные: почту, сообщения, изображения. В этом уроке вы научитесь делать сетевые запросы REST и разбирать ответы JSON в приложении **Mars Photos**, которое загружает фотографии поверхности Марса.

### Необходимые условия

- Умение создавать компоненты и работать с состоянием (`useState`, `useEffect`).
- Базовое представление о промисах и `async`/`await`.

### Что вы узнаете

- Что такое веб-сервис REST.
- Как выполнить запрос к REST API с помощью `fetch`.
- Как разобрать JSON-ответ в объекты TypeScript.
- Как обрабатывать состояния загрузки и ошибки.

### Что вы создадите

Приложение **Mars Photos**, которое получает список URL фотографий Марса с веб-сервиса и показывает количество полученных фотографий.

## Что такое REST

**REST** (Representational State Transfer) — архитектурный стиль веб-сервисов. Клиент обращается к серверу по HTTP-методам:

- `GET` — получить данные;
- `POST` — создать;
- `PUT` / `PATCH` — обновить;
- `DELETE` — удалить.

Данные обычно передаются в формате **JSON**.

Пример API, который мы будем использовать:

```
https://jsonplaceholder.typicode.com/photos
```

Он возвращает массив объектов:

```json
[
  { "id": 1, "title": "Фото 1", "url": "https://.../photo1.jpg" },
  { "id": 2, "title": "Фото 2", "url": "https://.../photo2.jpg" }
]
```

## Модель данных

Опишем тип, соответствующий JSON:

```tsx
export type MarsPhoto = {
  id: number
  title: string
  url: string
}
```

## Запрос через fetch

В React Native есть встроенная функция `fetch`, основанная на промисах:

```tsx
async function fetchPhotos(): Promise<MarsPhoto[]> {
  const response = await fetch(
    'https://jsonplaceholder.typicode.com/photos'
  )
  if (!response.ok) {
    throw new Error(`Ошибка сети: ${response.status}`)
  }
  const data = await response.json()
  return data as MarsPhoto[]
}
```

- `await fetch(...)` отправляет запрос и ждёт ответ.
- `response.ok` проверяет код ответа (200–299).
- `response.json()` разбирает тело ответа в объект.

## Состояние загрузки и ошибки

Сетевой запрос может занять время или завершиться ошибкой. Введём три состояния: данные, загрузка, ошибка.

```tsx
type UiState =
  | { status: 'loading' }
  | { status: 'success'; photos: MarsPhoto[] }
  | { status: 'error'; message: string }
```

## Главный компонент

Запустим запрос при монтировании компонента через `useEffect`:

```tsx
import { useEffect, useState } from 'react'

function MarsPhotosApp() {
  const [state, setState] = useState<UiState>({ status: 'loading' })

  useEffect(() => {
    fetchPhotos()
      .then((photos) => setState({ status: 'success', photos }))
      .catch((error) => setState({ status: 'error', message: error.message }))
  }, [])

  if (state.status === 'loading') {
    return <ActivityIndicator size="large" />
  }

  if (state.status === 'error') {
    return <Text>Не удалось загрузить фотографии: {state.message}</Text>
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>
        Получено фотографий: {state.photos.length}
      </Text>
    </View>
  )
}
```

Версия из этого урока не показывает сами изображения — она лишь выводит их количество, чтобы убедиться, что данные получены и разобраны. Отображение изображений мы добавим в практической работе 16.

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useEffect, useState } from 'react';
import { ActivityIndicator, StyleSheet, Text, View } from 'react-native';

type MarsPhoto = { id: number; title: string; url: string }

type UiState =
  | { status: 'loading' }
  | { status: 'success'; photos: MarsPhoto[] }
  | { status: 'error'; message: string }

async function fetchPhotos(): Promise<MarsPhoto[]> {
  const response = await fetch(
    'https://jsonplaceholder.typicode.com/photos'
  )
  if (!response.ok) {
    throw new Error(`Ошибка сети: ${response.status}`)
  }
  return (await response.json()) as MarsPhoto[]
}

function MarsPhotosApp() {
  const [state, setState] = useState<UiState>({ status: 'loading' })

  useEffect(() => {
    fetchPhotos()
      .then((photos) => setState({ status: 'success', photos }))
      .catch((error) => setState({ status: 'error', message: error.message }))
  }, [])

  if (state.status === 'loading') {
    return (
      <View style={styles.container}>
        <ActivityIndicator size="large" color="#3F51B5" />
      </View>
    )
  }

  if (state.status === 'error') {
    return (
      <View style={styles.container}>
        <Text style={styles.error}>Не удалось загрузить фотографии</Text>
        <Text>{state.message}</Text>
      </View>
    )
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Получено фотографий: {state.photos.length}</Text>
    </View>
  )
}

export default function App() {
  return (
    <>
      <MarsPhotosApp />
      <StatusBar style="auto" />
    </>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
    padding: 24,
  },
  title: { fontSize: 22, fontWeight: 'bold', textAlign: 'center' },
  error: { fontSize: 18, color: 'red', marginBottom: 8, textAlign: 'center' },
})
```

## Замечания

- Всегда проверяйте `response.ok` — иначе ошибка сервера не будет обнаружена.
- Не забывайте обрабатывать ошибки через `.catch` или `try/catch`.
- На время запроса показывайте индикатор загрузки, чтобы интерфейс оставался понятным.

## Резюме

- REST — стиль веб-сервисов, данные передаются в JSON.
- `fetch` выполняет сетевой запрос, `response.json()` разбирает ответ.
- Состояние приложения описывает три случая: загрузка, успех, ошибка.
- `useEffect` запускает запрос при монтировании компонента.
