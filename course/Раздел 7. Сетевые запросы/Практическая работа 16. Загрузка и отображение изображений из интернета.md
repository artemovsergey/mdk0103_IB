### Что вы создадите

## Как работает загрузка изображений

Отображение изображения по URL требует: загрузки, кэширования, декодирования и фоновой работы, чтобы интерфейс оставался отзывчивым. В React Native встроенный компонент **`Image`** умеет загружать изображения по `uri` и кэширует их автоматически — отдельная библиотека не нужна.

В React Native встроенный компонент **`Image`** умеет загружать изображения по `uri` и кэширует их автоматически — отдельная библиотека не нужна:

```tsx
<Image source={{ uri: photo.url }} style={styles.image} />
```

## Сетка изображений

`FlatList` поддерживает сетку через свойство `numColumns`. Чтобы при смене ориентации количество столбцов менялось, задайте `key`:

```tsx
const { width } = useWindowDimensions()
const numColumns = width > 600 ? 4 : 2

<FlatList
  key={numColumns}
  data={photos}
  numColumns={numColumns}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => (
    <Image source={{ uri: item.url }} style={styles.image} />
  )}
/>
```

> `key={numColumns}` обязателен: `FlatList` не поддерживает изменение `numColumns` на лету, поэтому при смене числа столбцов список пересоздаётся.

Стиль изображения:

```tsx
image: {
  flex: 1,
  aspectRatio: 1,
  margin: 4,
  borderRadius: 8,
  backgroundColor: '#E0E0E0',
},
```

`aspectRatio: 1` делает ячейку квадратной, а `backgroundColor` виден, пока изображение грузится.

## Состояния экрана

Опишем три состояния: загрузка, успех и ошибка. Ошибки обрабатываем через `catch`:

```tsx
type UiState =
  | { status: 'loading' }
  | { status: 'success'; photos: MarsPhoto[] }
  | { status: 'error'; message: string }
```

Хук из предыдущей лекции возвращает это состояние. Экран выбирает, что показать:

```tsx
function MarsPhotosScreen() {
  const state = useMarsPhotos()

  if (state.status === 'loading') {
    return (
      <View style={styles.center}>
        <ActivityIndicator size="large" color="#3F51B5" />
      </View>
    )
  }

  if (state.status === 'error') {
    return (
      <View style={styles.center}>
        <Text style={styles.error}>Не удалось загрузить фотографии</Text>
        <Text>{state.message}</Text>
      </View>
    )
  }

  return <PhotoGrid photos={state.photos} />
}
```

Анимация загрузки — `ActivityIndicator`, значок ошибки — сообщение с текстом.

## Полный код

```tsx
import { StatusBar } from 'expo-status-bar';
import { useEffect, useState } from 'react';
import {
  ActivityIndicator,
  FlatList,
  Image,
  StyleSheet,
  Text,
  useWindowDimensions,
  View,
} from 'react-native';

type MarsPhoto = { id: number; title: string; url: string }

type UiState =
  | { status: 'loading' }
  | { status: 'success'; photos: MarsPhoto[] }
  | { status: 'error'; message: string }

async function fetchPhotos(): Promise<MarsPhoto[]> {
  const response = await fetch(
    'https://jsonplaceholder.typicode.com/photos'
  )
  if (!response.ok) throw new Error(`Ошибка сети: ${response.status}`)
  return (await response.json()) as MarsPhoto[]
}

function PhotoGrid({ photos }: { photos: MarsPhoto[] }) {
  const { width } = useWindowDimensions()
  const numColumns = width > 600 ? 4 : 2

  return (
    <FlatList
      key={numColumns}
      data={photos}
      numColumns={numColumns}
      keyExtractor={(item) => item.id}
      contentContainerStyle={styles.grid}
      renderItem={({ item }) => (
        <Image source={{ uri: item.url }} style={styles.image} />
      )}
    />
  )
}

function MarsPhotosScreen() {
  const [state, setState] = useState<UiState>({ status: 'loading' })

  useEffect(() => {
    fetchPhotos()
      .then((photos) => setState({ status: 'success', photos }))
      .catch((error) => setState({ status: 'error', message: error.message }))
  }, [])

  if (state.status === 'loading') {
    return (
      <View style={styles.center}>
        <ActivityIndicator size="large" color="#3F51B5" />
      </View>
    )
  }

  if (state.status === 'error') {
    return (
      <View style={styles.center}>
        <Text style={styles.error}>Не удалось загрузить фотографии</Text>
        <Text>{state.message}</Text>
      </View>
    )
  }

  return <PhotoGrid photos={state.photos} />
}

export default function App() {
  return (
    <>
      <MarsPhotosScreen />
      <StatusBar style="auto" />
    </>
  );
}

const styles = StyleSheet.create({
  center: { flex: 1, alignItems: 'center', justifyContent: 'center', padding: 24 },
  grid: { padding: 4 },
  image: {
    flex: 1,
    aspectRatio: 1,
    margin: 4,
    borderRadius: 8,
    backgroundColor: '#E0E0E0',
  },
  error: { fontSize: 18, color: 'red', marginBottom: 8, textAlign: 'center' },
})
```

## Обработка ошибок

- Если сервер недоступен, `fetch` выбросит исключение, и экран покажет сообщение об ошибке.
- Если ответ не `ok`, мы сами выбрасываем ошибку с кодом статуса.
- Пока идёт загрузка, показывается `ActivityIndicator`.
