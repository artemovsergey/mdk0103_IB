# Лекция 4. Использование классов и объектов в TypeScript

До сих пор мы хранили данные в отдельных переменных. Но в реальных программах данные и действия над ними связаны между собой: у телевизора есть громкость, канал и методы «включить», «переключить канал». Для объединения данных и действий служат **классы** - основа объектно-ориентированного программирования (ООП).

На этом занятии вы научитесь объявлять классы, создавать объекты и использовать основные принципы ООП.

## Что вы узнаете

- Как объявлять классы и создавать их экземпляры (объекты).
- Как задавать свойства и методы, конструкторы.
- Как использовать модификаторы доступа (инкапсуляция).
- Как применять наследование и интерфейсы.

## Определение класса

Класс - это шаблон, по которому создаются объекты. Он описывает, какие **свойства** (данные) и **методы** (функции) будут у объектов.

```ts
class SmartDevice {
  name: string
  status: string

  constructor(name: string) {
    this.name = name
    this.status = "offline"
  }

  turnOn(): void {
    this.status = "on"
    console.log(`${this.name} включён`)
  }

  turnOff(): void {
    this.status = "off"
    console.log(`${this.name} выключен`)
  }
}
```

Разберём объявление:

- `class SmartDevice` - объявление класса.
- `name: string` и `status: string` - свойства (данные объекта).
- `constructor(name: string)` - специальный метод, который вызывается при создании объекта и задаёт начальные значения.
- `turnOn`, `turnOff` - методы (действия объекта).
- `this` - ссылка на текущий объект.

## Создание объектов

**Объект** (экземпляр класса) создаётся оператором `new`:

```ts
const tv = new SmartDevice("Телевизор")
tv.turnOn()        // Телевизор включён
tv.turnOff()       // Телевизор выключен
```

Можно создать сколько угодно объектов одного класса:

```ts
const tv = new SmartDevice("Телевизор")
const light = new SmartDevice("Лампа")

tv.turnOn()        // Телевизор включён
light.turnOn()     // Лампа включён
```

## Инкапсуляция и модификаторы доступа

**Инкапсуляция** - принцип ООП, по которому внутренние данные объекта скрыты от внешнего кода, а доступ к ним идёт через методы. Для этого используют модификаторы доступа:

| Модификатор | Доступ |
|:------------|:-------|
| `public` (по умолчанию) | из любого места |
| `private` | только внутри класса |
| `protected` | внутри класса и его наследников |

```ts
class SmartTv {
  name: string
  private volume: number
  private channel: number

  constructor(name: string) {
    this.name = name
    this.volume = 5
    this.channel = 1
  }

  increaseVolume(): void {
    if (this.volume < 10) {
      this.volume++
    }
    console.log(`Громкость: ${this.volume}`)
  }

  changeChannel(channel: number): void {
    this.channel = channel
    console.log(`Канал: ${this.channel}`)
  }
}
```

Свойства `volume` и `channel` объявлены как `private`, поэтому извне они недоступны:

```ts
const tv = new SmartTv("Телевизор")
tv.increaseVolume()      // Громкость: 6
tv.changeChannel(5)      // Канал: 5
// tv.volume = 100       // Ошибка: свойство private
```

## Наследование

**Наследование** - принцип ООП, позволяющий создать новый класс на основе существующего. Новый класс (наследник) получает все свойства и методы родителя и может добавлять свои.

В TypeScript наследование задаётся ключевым словом `extends`, а переопределение метода - `override`:

```ts
class SmartDevice {
  name: string
  protected status: string

  constructor(name: string) {
    this.name = name
    this.status = "off"
  }

  turnOn(): void {
    this.status = "on"
    console.log(`${this.name} включён`)
  }
}

class SmartTvDevice extends SmartDevice {
  private volume: number

  constructor(name: string) {
    super(name)          // вызов конструктора родителя
    this.volume = 5
  }

  override turnOn(): void {
    super.turnOn()       // вызов метода родителя
    console.log(`Громкость: ${this.volume}`)
  }
}

const tv = new SmartTvDevice("Телевизор")
tv.turnOn()
```

Вывод:

```
Телевизор включён
Громкость: 5
```

- `extends` - наследование от родительского класса.
- `super(name)` - вызов конструктора родителя (обязателен, если у родителя есть конструктор с параметрами).
- `super.turnOn()` - вызов метода родителя.
- `override` - пометка переопределённого метода (TypeScript проверяет, что такой метод действительно есть у родителя).

## IS-A и HAS-A

При проектировании классов различают два вида отношений:

- **IS-A** («является») - наследование. Телевизор **является** умным устройством: `class SmartTv extends SmartDevice`.
- **HAS-A** («содержит») - композиция. Умный дом **содержит** список устройств:

```ts
class SmartHome {
  private devices: SmartDevice[] = []

  addDevice(device: SmartDevice): void {
    this.devices.push(device)
    console.log(`Устройство ${device.name} добавлено`)
  }

  turnOnAll(): void {
    this.devices.forEach((device) => device.turnOn())
  }

  get count(): number {
    return this.devices.length
  }
}
```

## Интерфейсы

**Интерфейс** описывает форму объекта - какие свойства и методы у него должны быть, но не содержит реализации. Класс реализует интерфейс ключевым словом `implements`:

```ts
interface Switchable {
  turnOn(): void
  turnOff(): void
}

class Lamp implements Switchable {
  name: string

  constructor(name: string) {
    this.name = name
  }

  turnOn(): void {
    console.log(`${this.name}: свет включён`)
  }

  turnOff(): void {
    console.log(`${this.name}: свет выключен`)
  }
}
```

Класс, реализующий интерфейс, обязан определить все его методы, иначе TypeScript выдаст ошибку.

## Программа целиком

Создайте файл `main.ts`:

```ts
class SmartDevice {
  name: string
  protected status: string

  constructor(name: string) {
    this.name = name
    this.status = "off"
  }

  turnOn(): void {
    this.status = "on"
    console.log(`${this.name} включён`)
  }

  turnOff(): void {
    this.status = "off"
    console.log(`${this.name} выключен`)
  }
}

class SmartTvDevice extends SmartDevice {
  private volume: number

  constructor(name: string) {
    super(name)
    this.volume = 5
  }

  increaseVolume(): void {
    this.volume++
    console.log(`Громкость: ${this.volume}`)
  }
}

class SmartHome {
  private devices: SmartDevice[] = []

  addDevice(device: SmartDevice): void {
    this.devices.push(device)
  }

  turnOnAll(): void {
    this.devices.forEach((device) => device.turnOn())
  }
}

const home = new SmartHome()
const tv = new SmartTvDevice("Телевизор")

home.addDevice(tv)
home.turnOnAll()      // Телевизор включён
tv.increaseVolume()   // Громкость: 6
```

Запустите:

```bash
node main.ts
```

## Резюме

- Класс объединяет свойства и методы; объект создаётся через `new`.
- Конструктор задаёт начальные значения свойств.
- Инкапсуляция скрывает данные с помощью `private` и `protected`.
- Наследование (`extends`) позволяет переиспользовать код родителя.
- `super` вызывает конструктор или метод родителя.
- Интерфейсы (`implements`) описывают форму класса.
- Отношения: IS-A (наследование) и HAS-A (композиция).
