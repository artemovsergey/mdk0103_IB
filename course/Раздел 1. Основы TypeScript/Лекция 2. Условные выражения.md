# Лекция 2. Условные выражения в TypeScript

Программа не всегда выполняется строка за строкой. Часто нужно, чтобы поведение зависело от условий: «если пользователь нажал кнопку - сделать одно, иначе - другое». Для этого используются **условные выражения**.

На этом занятии вы научитесь управлять ходом программы с помощью `if`/`else`, тернарного оператора и `switch`.

## Что вы узнаете

- Как выполнять код по условию с помощью `if` и `else`.
- Как использовать тернарный оператор `?:`.
- Как обрабатывать несколько вариантов с помощью `switch`.
- Как сравнивать значения и объединять условия.

## Операторы сравнения

Условие - это выражение, которое вычисляется в `true` (истина) или `false` (ложь). Для сравнения значений используются операторы:

| Оператор | Значение | Пример (результат) |
|:---------|:---------|:-------------------|
| `===` | равно | `5 === 5` → `true` |
| `!==` | не равно | `5 !== 3` → `true` |
| `>` | больше | `5 > 3` → `true` |
| `<` | меньше | `10 < 5` → `false` |
| `>=` | больше или равно | `5 >= 5` → `true` |
| `<=` | меньше или равно | `4 <= 3` → `false` |

> В TypeScript для сравнения используется строгое равенство `===` (тройной знак). Оно проверяет и значение, и тип. Обычное `==` может давать неожиданные результаты, поэтому его лучше не использовать.

## Операторы условий и логические операторы

Условия можно объединять с помощью логических операторов:

```ts
const a = true
const b = false

console.log(a && b)   // false - логическое И (оба истинны)
console.log(a || b)   // true  - логическое ИЛИ (хотя бы одно истинно)
console.log(!a)       // false - логическое НЕ (отрицание)
```

## Условный оператор if

Конструкция `if` выполняет блок кода, только если условие истинно:

```ts
const temperature = 25

if (temperature > 20) {
  console.log("На улице тепло")
}
```

Если условие ложно, блок пропускается. Добавим `else`, чтобы обработать противоположный случай:

```ts
const temperature = 5

if (temperature > 20) {
  console.log("На улице тепло")
} else {
  console.log("На улице прохладно")
}
```

## Несколько условий: else if

Для проверки нескольких условий подряд используется `else if`:

```ts
const hour = 14

if (hour < 6) {
  console.log("Ночь")
} else if (hour < 12) {
  console.log("Утро")
} else if (hour < 18) {
  console.log("День")
} else {
  console.log("Вечер")
}
```

Проверки выполняются сверху вниз, и выполняется блок первой истинной ветки. Остальные пропускаются.

## Тернарный оператор

Короткую запись «если-иначе» даёт тернарный оператор `условие ? значение1 : значение2`:

```ts
const age = 20
const access = age >= 18 ? "Разрешено" : "Запрещено"
console.log(access)   // Разрешено
```

Он удобен, когда нужно выбрать одно из двух значений, а не выполнить блок кода.

## Оператор switch

Когда нужно сравнить переменную с несколькими конкретными значениями, используют `switch`:

```ts
const grade = 5

switch (grade) {
  case 5:
    console.log("Отлично")
    break
  case 4:
    console.log("Хорошо")
    break
  case 3:
    console.log("Удовлетворительно")
    break
  case 2:
    console.log("Неудовлетворительно")
    break
  default:
    console.log("Неверная оценка")
}
```

- `case значение:` - проверка на совпадение.
- `break` - выход из `switch`. Без него выполнение «провалится» в следующую ветку.
- `default` - ветка, которая выполняется, если ни одна не совпала.

## Проверка на вхождение в диапазон

Диапазон значений проверяют двумя сравнениями:

```ts
const number = 7

if (number >= 1 && number <= 10) {
  console.log("Число в диапазоне от 1 до 10")
}
```

## Программа целиком

Создайте файл `main.ts`:

```ts
function timeOfDay(hour: number): string {
  if (hour < 6) return "Ночь"
  if (hour < 12) return "Утро"
  if (hour < 18) return "День"
  if (hour < 24) return "Вечер"
  return "Неверное время"
}

console.log(`Сейчас: ${timeOfDay(14)}`)
```

Запустите:

```bash
node main.ts
```

Вывод:

```
Сейчас: День
```

## Резюме

- Условия вычисляются в `true` или `false`.
- `if`/`else if`/`else` выполняют код по условию.
- Тернарный оператор `?:` выбирает одно из двух значений.
- `switch` обрабатывает несколько конкретных вариантов.
- Сравнение выполняется операторами `===`, `!==`, `>`, `<`, `>=`, `<=`.
- Логические операторы `&&`, `||`, `!` объединяют условия.
