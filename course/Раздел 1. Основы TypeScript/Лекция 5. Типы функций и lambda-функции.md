# Лекция 5. Типы функций и лямбда-выражения в TypeScript

В TypeScript функция - это такой же объект, как число или строка. Её можно сохранить в переменную, передать в другую функцию как аргумент и вернуть из функции. Такие функции называются **лямбда-выражениями** (или стрелочными функциями), а функции, работающие с другими функциями, - функциями высшего порядка.

На этом занятии вы научитесь работать с функциями как со значениями.

## Что вы узнаете

- Как сохранять функции в переменных.
- Как описывать тип функции.
- Как передавать функции в качестве аргументов.
- Как использовать встроенные функции высшего порядка.

## Функция как значение

Функцию можно присвоить переменной. При этом стрелочную функцию записывают без имени:

```ts
const greet = (name: string): void => {
  console.log(`Привет, ${name}!`)
}

greet("Иван")   // Привет, Иван!
```

Здесь `greet` - это переменная, хранящая функцию. Обратите внимание на стрелку `=>`: такая запись называется **стрелочной функцией**.

## Тип функции

У функции, как и у любого значения, есть тип. Тип функции описывает её параметры и возвращаемое значение:

```ts
const add: (a: number, b: number) => number = (a, b) => a + b
const print: (text: string) => void = (text) => console.log(text)
```

Разберём тип `(a: number, b: number) => number`:

- в круглых скобках - типы параметров;
- после стрелки `=>` - тип возвращаемого значения.

Типы функций можно описывать отдельным псевдонимом:

```ts
type Operation = (a: number, b: number) => number

const add: Operation = (a, b) => a + b
const multiply: Operation = (a, b) => a * b
```

## Функция как аргумент (callback)

Функцию можно передать в другую функцию как аргумент. Такая передаваемая функция называется **callback** (функция обратного вызова):

```ts
function apply(a: number, b: number, operation: (x: number, y: number) => number): number {
  return operation(a, b)
}

console.log(apply(3, 4, (x, y) => x + y))   // 7
console.log(apply(3, 4, (x, y) => x * y))   // 12
```

Функция `apply` принимает три параметра, третий из которых - функция. Внутри она вызывает переданную функцию.

## Короткая запись стрелочной функции

Если стрелочная функция состоит из одного выражения, фигурные скобки и `return` можно опустить:

```ts
// Длинная запись
const double = (n: number): number => {
  return n * 2
}

// Короткая запись (эквивалентна)
const double = (n: number): number => n * 2
```

## Передача лямбды в функции высшего порядка

Лямбда-выражения чаще всего используют с функциями высшего порядка, например при работе с массивами:

```ts
const numbers = [1, 2, 3, 4, 5]

numbers.forEach((n) => console.log(n))

const squares = numbers.map((n) => n * n)
console.log(squares)   // [ 1, 4, 9, 16, 25 ]
```

Внутри `forEach` и `map` мы передаём лямбда-выражение `(n) => ...`, которое выполняется для каждого элемента.

## Повторение действия несколько раз

Чтобы выполнить действие заданное число раз, в TypeScript нет готовой функции `repeat`, но её легко написать:

```ts
function repeat(times: number, action: (index: number) => void): void {
  for (let i = 0; i < times; i++) {
    action(i)
  }
}

repeat(3, (i) => console.log(`Итерация ${i}`))
```

Вывод:

```
Итерация 0
Итерация 1
Итерация 2
```

## Функция, возвращающая функцию

Функция может возвращать другую функцию:

```ts
function createMultiplier(factor: number): (n: number) => number {
  return (n) => n * factor
}

const double = createMultiplier(2)
const triple = createMultiplier(3)

console.log(double(5))   // 10
console.log(triple(5))   // 15
```

## Программа целиком

Создайте файл `main.ts`:

```ts
type Operation = (a: number, b: number) => number

function calculate(a: number, b: number, operation: Operation): number {
  return operation(a, b)
}

const sum = calculate(10, 5, (x, y) => x + y)
const product = calculate(10, 5, (x, y) => x * y)

console.log(`Сумма: ${sum}`)
console.log(`Произведение: ${product}`)
```

Запустите:

```bash
node main.ts
```

Вывод:

```
Сумма: 15
Произведение: 50
```

## Резюме

- Функция может храниться в переменной и передаваться как аргумент.
- Стрелочная функция записывается как `(параметры) => выражение`.
- Тип функции описывается как `(параметры) => возвращаемое_значение`.
- Функция, переданная в другую функцию, называется callback.
- Функции высшего порядка упрощают работу с массивами.
