# Лекция 1. Создание и использование функций в TypeScript

В программировании часто бывает нужно выполнить один и тот же блок кода несколько раз. Например, приложение печатает приветствие для каждого пользователя. Вместо того чтобы писать один и тот же код снова и снова, его выносят в **функцию** - именованный блок кода, который можно вызвать в нужном месте.

На этом занятии вы научитесь объявлять функции, передавать в них данные (параметры) и получать результат (возвращаемое значение).

## Что вы узнаете

- Как объявлять и вызывать функции.
- Как передавать параметры и возвращать значение.
- Как задавать параметры по умолчанию.

## Объявление и вызов функции

Функция объявляется с помощью ключевого слова `function`, после которого идут имя, список параметров в круглых скобках и тело в фигурных скобках.

```ts
function greet(name: string): void {
  console.log(`Привет, ${name}!`)
}
```

- `greet` - имя функции.
- `name: string` - параметр (данные, которые функция принимает).
- `: void` - тип возвращаемого значения. `void` означает, что функция ничего не возвращает.

Функция вызывается по имени с передачей аргументов:

```ts
greet("Иван")   // Выведет: Привет, Иван!
greet("Мария")  // Выведет: Привет, Мария!
```

## Возвращаемое значение

Чтобы функция вернула результат, используется оператор `return`. Тип возвращаемого значения указывается после списка параметров:

```ts
function add(a: number, b: number): number {
  return a + b
}

const sum = add(3, 4)
console.log(sum)   // 7
```

Когда выполняется `return`, функция завершает работу и передаёт значение туда, где была вызвана.

Если функция не возвращает значения (а, например, только печатает), её тип - `void`.

## Функции без параметров

Функция может не иметь параметров:

```ts
function printLine(): void {
  console.log("----------")
}

printLine()
```

## Параметры по умолчанию

Параметру можно задать значение по умолчанию. Если при вызове аргумент не передан, используется значение по умолчанию:

```ts
function greet(name: string = "Гость"): void {
  console.log(`Привет, ${name}!`)
}

greet()          // Привет, Гость!
greet("Иван")    // Привет, Иван!
```

## Стрелочные функции

В TypeScript есть ещё один, более короткий способ записи функций - **стрелочные функции**:

```ts
const add = (a: number, b: number): number => {
  return a + b
}

console.log(add(3, 4))   // 7
```

Если тело функции состоит из одного выражения, можно записать ещё короче, без `return` и фигурных скобок:

```ts
const add = (a: number, b: number): number => a + b
```

Стрелочные функции особенно удобны, когда функцию нужно передать как аргумент. Подробнее об этом - в лекции про типы функций и лямбда-выражения.

## Программа целиком

Объединим всё в одну программу. Создайте файл `main.ts`:

```ts
function calculateArea(width: number, height: number): number {
  return width * height
}

function printArea(width: number, height: number): void {
  const area = calculateArea(width, height)
  console.log(`Площадь прямоугольника: ${area}`)
}

printArea(10, 5)
```

Запустите:

```bash
node main.ts
```

Вывод:

```
Площадь прямоугольника: 50
```

## Резюме

- Функция - это именованный блок кода, который можно вызывать многократно.
- Функции объявляются через `function` или как стрелочные функции.
- Параметры - это входные данные функции; возвращаемое значение - результат её работы.
- Тип `void` означает, что функция ничего не возвращает.
- Параметрам можно задавать значения по умолчанию.
