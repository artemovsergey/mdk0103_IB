## Теоретическая часть

### Классы в TypeScript
Класс — это шаблон для создания объектов. Он определяет свойства (данные) и методы (функции), которые будут у объектов.

**Пример объявления класса:**
```ts
class SmartDevice {
  name: string
  status: string

  constructor(name: string) {
    this.name = name
    this.status = "online"
  }

  turnOn(): void {
    console.log("Device is turned on")
  }

  turnOff(): void {
    console.log("Device is turned off")
  }
}
```

### Объекты и экземпляры классов
Объект — это экземпляр класса. Можно создавать несколько объектов одного класса.

**Пример создания объекта:**
```ts
const smartTv = new SmartDevice("Телевизор")
smartTv.turnOn()
```

### Конструкторы
Конструктор — это специальный метод, который вызывается при создании объекта и задаёт начальные значения свойств.

**Пример конструктора:**
```ts
class SmartDevice {
  name: string
  category: string
  status: string

  constructor(name: string, category: string) {
    this.name = name
    this.category = category
    this.status = "online"
  }
}
```

### Наследование
Наследование позволяет создавать новый класс на основе существующего с помощью ключевого слова `extends`.

**Пример наследования:**
```ts
class SmartTvDevice extends SmartDevice {
  constructor(name: string, category: string) {
    super(name, category)   // вызов конструктора родителя
  }
}
```

## Практический пример

**Задача:** Создать систему управления умным домом с устройствами разных типов.

```ts
// Базовый класс для всех умных устройств
class SmartDevice {
  name: string
  category: string
  protected status: string

  constructor(name: string, category: string) {
    this.name = name
    this.category = category
    this.status = "online"
  }

  turnOn(): void {
    this.status = "on"
    console.log(`${this.name} is turned on`)
  }

  turnOff(): void {
    this.status = "off"
    console.log(`${this.name} is turned off`)
  }

  getStatus(): string {
    return this.status
  }
}

// Класс для умного телевизора
class SmartTvDevice extends SmartDevice {
  private volume: number
  private channel: number

  constructor(name: string, category: string) {
    super(name, category)
    this.volume = 5
    this.channel = 1
  }

  increaseVolume(): void {
    if (this.volume < 10) this.volume++
    console.log(`Volume increased to ${this.volume}`)
  }

  changeChannel(newChannel: number): void {
    this.channel = newChannel
    console.log(`Channel changed to ${this.channel}`)
  }

  override turnOn(): void {
    super.turnOn()
    console.log(`TV is ready with volume ${this.volume} and channel ${this.channel}`)
  }
}

// Класс для умной лампы
class SmartLightDevice extends SmartDevice {
  private brightness: number

  constructor(name: string, category: string) {
    super(name, category)
    this.brightness = 50
  }

  increaseBrightness(): void {
    if (this.brightness < 100) this.brightness += 10
    console.log(`Brightness increased to ${this.brightness}`)
  }

  override turnOn(): void {
    super.turnOn()
    console.log(`Light is on with brightness ${this.brightness}`)
  }
}

// Класс для управления умным домом
class SmartHome {
  private devices: SmartDevice[] = []

  addDevice(device: SmartDevice): void {
    this.devices.push(device)
    console.log(`Device ${device.name} added to smart home`)
  }

  turnOnAllDevices(): void {
    this.devices.forEach((device) => device.turnOn())
  }

  turnOffAllDevices(): void {
    this.devices.forEach((device) => device.turnOff())
  }

  getDeviceStatus(): string {
    const online = this.devices.filter((d) => d.getStatus() === "on").length
    return `Total devices: ${this.devices.length}. Online: ${online}`
  }
}

// Использование системы
const smartHome = new SmartHome()

const tv = new SmartTvDevice("Living Room TV", "Entertainment")
const light = new SmartLightDevice("Kitchen Light", "Lighting")

smartHome.addDevice(tv)
smartHome.addDevice(light)

smartHome.turnOnAllDevices()
tv.increaseVolume()
tv.changeChannel(5)
light.increaseBrightness()

console.log(smartHome.getDeviceStatus())

smartHome.turnOffAllDevices()
```
