# Практическая работа 4. Работа с коллекциями в TypeScript

## Тема
Использование коллекций (массивы, множества, словари) в TypeScript.

## Цель
Научиться создавать, модифицировать и использовать различные типы коллекций (массив, Set, Map) для решения практических задач. Закрепить навыки работы с циклами, условными выражениями и функциями высшего порядка.

## Теоретическая часть
Коллекции – это структуры данных, которые позволяют хранить группы элементов. В TypeScript основные типы коллекций:
- **Массив** (`Array`) – упорядоченная коллекция элементов, доступ по индексу.
- **Set** – коллекция уникальных элементов.
- **Map** – коллекция пар "ключ-значение".

Подробнее с теорией можно ознакомиться в файле `Лекция 3. Коллекции.md`.

## Практический пример

```ts
// Пример работы с массивом
const planets = ["Mercury", "Venus", "Earth", "Mars"]
planets.push("Jupiter")
console.log(`Third planet: ${planets[2]}`)

// Пример работы со словарём
const moons = new Map<string, number>([
  ["Earth", 1],
  ["Mars", 2],
])
console.log(`Moons of Mars: ${moons.get("Mars")}`)
```
