# Лекция 3. Функции высшего порядка с коллекциями

Функции высшего порядка - это функции, которые принимают другие функции как параметры и/или возвращают функцию. Они особенно полезны при работе с коллекциями: сортировка, фильтрация и преобразование занимают гораздо меньше кода, чем с обычными циклами.

На этом занятии вы познакомитесь с основными функциями высшего порядка для массивов: `forEach`, `map`, `filter`, `groupBy`, `fold` (аналог `reduce`) и `sort`.

## Что вы узнаете

- Как перебирать элементы с помощью `forEach`.
- Как преобразовывать элементы с помощью `map`.
- Как отбирать элементы с помощью `filter`.
- Как группировать и сворачивать массивы.

## Исходные данные

В примерах будем работать с меню пекарни - массивом объектов. Каждый объект описывает один вид печенья:

```ts
type Cookie = {
  name: string
  softBaked: boolean
  hasFilling: boolean
  price: number
}

const cookies: Cookie[] = [
  { name: "Шоколадное", softBaked: false, hasFilling: false, price: 1.5 },
  { name: "Овсяное", softBaked: true, hasFilling: false, price: 2.0 },
  { name: "С джемом", softBaked: true, hasFilling: true, price: 2.5 },
  { name: "Ореховое", softBaked: false, hasFilling: true, price: 2.0 },
]
```

## forEach()

Функция `forEach` выполняет переданную функцию для каждого элемента массива. Она ничего не возвращает:

```ts
cookies.forEach((cookie) => {
  console.log(cookie.name)
})
```

Вывод:

```
Шоколадное
Овсяное
С джемом
Ореховое
```

## map()

Функция `map` преобразует каждый элемент и возвращает **новый массив** из результатов. Исходный массив не меняется:

```ts
const names = cookies.map((cookie) => cookie.name)
console.log(names)
```

Вывод:

```
[ 'Шоколадное', 'Овсяное', 'С джемом', 'Ореховое' ]
```

## filter()

Функция `filter` возвращает новый массив из элементов, для которых переданная функция вернула `true`:

```ts
const softCookies = cookies.filter((cookie) => cookie.softBaked)
console.log(softCookies.map((cookie) => cookie.name))
```

Вывод:

```
[ 'Овсяное', 'С джемом' ]
```

## groupBy()

В TypeScript нет готовой встроенной функции `groupBy`, поэтому группировку пишут с помощью `reduce`. `reduce` сворачивает массив в одно значение.

Разберём `reduce` на простом примере - сумме цен:

```ts
const totalPrice = cookies.reduce((sum, cookie) => sum + cookie.price, 0)
console.log(totalPrice)   // 8
```

- Первый параметр `reduce` - функция-свёртка: она получает накопленное значение (`sum`) и текущий элемент (`cookie`).
- Второй параметр `0` - начальное значение аккумулятора.

Теперь сгруппируем печенье по признаку «мягкое / хрустящее»:

```ts
const grouped = cookies.reduce((groups, cookie) => {
  const key = cookie.softBaked ? "мягкое" : "хрустящее"
  if (!groups[key]) groups[key] = []
  groups[key].push(cookie.name)
  return groups
}, {} as Record<string, string[]>)

console.log(grouped)
```

Вывод:

```
{ хрустящее: [ 'Шоколадное', 'Ореховое' ], мягкое: [ 'Овсяное', 'С джемом' ] }
```

## sort()

Функция `sort` сортирует массив. Чтобы отсортировать по определённому полю, передают функцию сравнения:

```ts
const sorted = cookies.map((c) => ({ name: c.name, price: c.price }))
sorted.sort((a, b) => a.price - b.price)
console.log(sorted)
```

Функция сравнения возвращает:

- отрицательное число, если `a` должно идти раньше `b`;
- положительное число, если `a` должно идти позже;
- `0`, если порядок не важен.

Вывод:

```
[ { name: 'Шоколадное', price: 1.5 },
  { name: 'Овсяное', price: 2 },
  { name: 'Ореховое', price: 2 },
  { name: 'С джемом', price: 2.5 } ]
```

## Цепочки вызовов

Функции высшего порядка удобно объединять в цепочки - результат одной функции передаётся в другую:

```ts
const expensiveSoftNames = cookies
  .filter((cookie) => cookie.softBaked)
  .filter((cookie) => cookie.price >= 2)
  .map((cookie) => cookie.name)

console.log(expensiveSoftNames)   // [ 'Овсяное', 'С джемом' ]
```

## Сводка функций

| Функция | Что делает | Возвращает |
|:--------|:-----------|:-----------|
| `forEach` | выполняет функцию для каждого элемента | ничего (`void`) |
| `map` | преобразует каждый элемент | новый массив |
| `filter` | отбирает элементы по условию | новый массив |
| `reduce` | сворачивает массив в одно значение | одно значение |
| `sort` | сортирует элементы | отсортированный массив |

## Резюме

- Функция высшего порядка принимает другую функцию как параметр.
- `forEach` - перебор без возврата результата.
- `map` - преобразование элементов в новый массив.
- `filter` - отбор элементов по условию.
- `reduce` - сворачивание массива в одно значение (аналог `fold`).
- Функции объединяются в цепочки для решения сложных задач.
