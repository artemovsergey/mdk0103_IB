# Лекция 6. Асинхронность в TypeScript

До сих пор наши программы выполнялись строго по порядку: одна строка за другой. Такой код называется **синхронным**. Но в мобильных приложениях часто нужно выполнять долгие операции (запрос к серверу, чтение файла), не «замораживая» приложение. Для этого используется **асинхронное программирование**.

В TypeScript для этого есть `Promise` и `async`/`await`. На этом занятии вы научитесь писать асинхронный код.

## Что вы узнаете

- Чем асинхронный код отличается от синхронного.
- Как отложить выполнение кода с помощью `setTimeout`.
- Как работать с `Promise` и `async`/`await`.
- Как обрабатывать ошибки и запускать задачи параллельно.

## Синхронный код

В синхронном коде каждая строка выполняется после завершения предыдущей:

```ts
console.log("Первый")
console.log("Второй")
console.log("Третий")
```

Вывод:

```
Первый
Второй
Третий
```

## Асинхронный код и setTimeout

Асинхронная операция не блокирует выполнение остального кода. Функция `setTimeout` откладывает выполнение функции на заданное время (в миллисекундах):

```ts
console.log("Начало")

setTimeout(() => {
  console.log("Прошло 2 секунды")
}, 2000)

console.log("Конец")
```

Вывод:

```
Начало
Конец
Прошло 2 секунды
```

Обратите внимание: «Конец» печатается **до** сообщения внутри `setTimeout`, хотя в коде он стоит после. Программа не ждёт завершения отложенной задачи, а продолжает выполняться дальше.

## Promise

**Promise** (обещание) - это объект, представляющий результат операции, которая завершится в будущем. У Promise есть два возможных исхода:

- **успех** (fulfilled) - операция завершилась с результатом;
- **ошибка** (rejected) - операция завершилась неудачей.

Создадим функцию, возвращающую Promise:

```ts
function fetchData(): Promise<string> {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve("Данные получены")
    }, 1000)
  })
}
```

- `new Promise(...)` создаёт Promise.
- `resolve(значение)` сообщает, что операция завершилась успешно, и передаёт результат.

## async и await

Ключевое слово `await` заставляет функцию дождаться завершения Promise, а `async` помечает функцию, внутри которой можно использовать `await`:

```ts
async function main(): Promise<void> {
  console.log("Загрузка...")
  const data = await fetchData()
  console.log(data)
}

main()
```

Вывод:

```
Загрузка...
Данные получены
```

- `async function` - объявление асинхронной функции.
- `await fetchData()` - «подожди, пока Promise завершится, и верни результат».
- Асинхронная функция всегда возвращает Promise.

## Обработка ошибок: try/catch

Если асинхронная операция может завершиться с ошибкой, ошибку ловят конструкцией `try/catch`:

```ts
function fetchWithError(): Promise<string> {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      reject("Сервер недоступен")
    }, 1000)
  })
}

async function main(): Promise<void> {
  try {
    const data = await fetchWithError()
    console.log(data)
  } catch (error) {
    console.log(`Ошибка: ${error}`)
  }
}

main()
```

Вывод:

```
Ошибка: Сервер недоступен
```

- `reject(ошибка)` сообщает, что операция завершилась неудачей.
- `try` содержит код, где может произойти ошибка.
- `catch (error)` выполняется, если в `try` произошла ошибка.

## Параллельное выполнение: Promise.all

Иногда нужно запустить несколько независимых задач одновременно и дождаться их всех. Для этого используется `Promise.all`:

```ts
async function main(): Promise<void> {
  const [a, b] = await Promise.all([fetchData(), fetchData()])
  console.log(a, b)
}

main()
```

Обе задачи запускаются одновременно, а `await` дожидается их завершения.

## Имитация задержки

Полезная утилита для примеров - функция, которая «ждёт» заданное время:

```ts
function delay(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms))
}

async function main(): Promise<void> {
  console.log("Ждём...")
  await delay(1000)
  console.log("Готово")
}

main()
```

## Программа целиком

Создайте файл `main.ts`:

```ts
function delay(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms))
}

async function download(file: string): Promise<string> {
  console.log(`Скачивание ${file}...`)
  await delay(1000)
  return `${file} скачан`
}

async function main(): Promise<void> {
  const results = await Promise.all([
    download("a.txt"),
    download("b.txt"),
  ])
  results.forEach((r) => console.log(r))
}

main()
```

Запустите:

```bash
node main.ts
```

Вывод (обе задачи выполняются параллельно):

```
Скачивание a.txt...
Скачивание b.txt...
a.txt скачан
b.txt скачан
```

## Резюме

- Синхронный код выполняется по порядку, асинхронный - не блокирует программу.
- `setTimeout` откладывает выполнение функции.
- `Promise` представляет результат будущей операции.
- `async`/`await` позволяют писать асинхронный код, как синхронный.
- Ошибки ловятся конструкцией `try/catch`.
- `Promise.all` запускает несколько задач параллельно.
