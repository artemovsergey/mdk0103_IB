### Теоретическая часть

Циклы позволяют выполнять блок кода многократно. В TypeScript есть три основных типа циклов:

- **`for`** — используется для повторения с заданным числом итераций.
- **`while`** — выполняется пока условие истинно.
- **`do-while`** — выполняется хотя бы один раз, затем проверяет условие.

#### Примеры:

```ts
// Цикл for
for (let i = 1; i <= 5; i++) {
  console.log(i) // 1, 2, 3, 4, 5
}

// Цикл while
let x = 5
while (x > 0) {
  console.log(x)
  x--
}

// Цикл do-while
let y = 0
do {
  console.log(y)
  y++
} while (y < 3)
```

### Практический пример

```ts
const planets = ["Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune"]

// Цикл for...of для перебора массива
console.log("Planets in solar system:")
for (const planet of planets) {
  console.log(planet)
}

// Цикл for с индексом
console.log("\nPlanets with index:")
for (let i = 0; i < planets.length; i++) {
  console.log(`Planet ${i + 1}: ${planets[i]}`)
}

// Цикл while
let count = 5
console.log("\nCountdown:")
while (count > 0) {
  console.log(count)
  count--
}
```
