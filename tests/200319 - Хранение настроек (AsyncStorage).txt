##01::3
Для чего используется AsyncStorage?
Для хранения простых настроек по принципу ключ — значение
Для создания анимаций интерфейса
Для сетевых запросов к серверу
Для навигации между экранами
##02::3
Какие данные хранит AsyncStorage?
Строки
Только числа
Изображения
Таблицы базы данных

##15::3
Зачем нужно состояние ready в приложении?
Чтобы не показывать интерфейс до чтения сохранённой настройки
Чтобы считать количество релизов
Чтобы подключиться к базе данных
Чтобы проверить интернет-соединение

##19::3
Когда вместо AsyncStorage лучше использовать SQLite?
Для структурированных данных и запросов с фильтрацией
Для хранения одной простой настройки
Для сохранения флага темы
Для хранения пары строк
##20::3
Чем AsyncStorage отличается от SQLite по объёму и сложности?
AsyncStorage проще и подходит для малых объёмов данных
AsyncStorage сложнее и требует SQL-запросов
Они полностью одинаковы
SQLite не поддерживает фильтрацию данных
